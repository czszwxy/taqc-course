# Регулярні вирази

Перевірити формат промокоду, витягти номери замовлень з листа клієнта, розібрати рядок логу, сховати email і номер картки перед записом у лог — усе це задачі для **регулярних виразів** (regex): міні-мови для опису шаблонів тексту. У Python за неї відповідає модуль `re`.

> [!TIP]
> Пиши й налагоджуй шаблон в онлайн-тестері (наприклад, regex101 з режимом Python) — він підсвічує збіги й пояснює кожен символ.

## Сирі рядки: r"..."

У шаблонах багато зворотних слешів: `\d` — цифра, `\.` — крапка. У звичайному рядку Python сам обробляє `\`, тому шаблони завжди пишуть як **сирі рядки**: `r"\d+"`.

## Функції модуля re

| Функція | Що робить | Повертає |
|---|---|---|
| `re.search(p, s)` | перший збіг **будь-де** | `Match` або `None` |
| `re.match(p, s)` | збіг лише **з початку** рядка | `Match` або `None` |
| `re.fullmatch(p, s)` | **увесь** рядок відповідає шаблону | `Match` або `None` |
| `re.findall(p, s)` | усі збіги | список рядків (або кортежів груп) |
| `re.finditer(p, s)` | усі збіги по одному | ітератор `Match` (є `.start()`, `.end()`) |
| `re.sub(p, repl, s)` | замінити всі збіги | новий рядок |
| `re.split(p, s)` | розбити за шаблоном | список |
| `re.compile(p)` | зібрати шаблон один раз | об'єкт з тими самими методами |

```python
import re

re.findall(r"ORD-\d+", "Orders ORD-1002 and ORD-1003 are late")   # ['ORD-1002', 'ORD-1003']
re.split(r"\s*[,;]\s*", "python, fastapi;sql ,  docker")            # ['python', 'fastapi', 'sql', 'docker']
```

## Основи синтаксису

| Запис | Означає | Приклад |
|---|---|---|
| `.` | будь-який символ (крім `\n`) | `a.c` → `abc`, `a-c` |
| `\d`, `\w`, `\s` | цифра, «буква / цифра / _», пробільний символ | `\d{4}` |
| `[a-z0-9]`, `[^,]` | один символ з набору / не з набору | `[A-Z]{3}` |
| `^`, `$` | початок / кінець рядка | `^GET` |
| `\b` | межа слова | `\bcat\b` не знайде `category` |
| `*`, `+`, `?` | 0+, 1+, 0 або 1 раз | `colou?r` |
| `{n}`, `{n,m}` | рівно n / від n до m разів | `\d{2,4}` |
| `( )` | група: захоплює частину збігу | `(\d+) UAH` |
| `(?P<name> )` | іменована група | `(?P<year>\d{4})` |
| `(?: )` | група без захоплення | `(?:GET\|POST)` |
| `a\|b` | або | `cat\|dog` |
| `\.`, `\(`, `\[` | сам символ, а не спецсимвол | `example\.com` |

## Розбір: іменовані групи на рядку логу

```python
LOG = re.compile(r"(?P<date>\d{4}-\d{2}-\d{2}) (?P<time>[\d:]+) (?P<level>[A-Z]+) (?P<message>.*)")

found = LOG.fullmatch("2026-03-20 10:15:02 ERROR payment gateway timeout")
found["level"]      # 'ERROR'
found["message"]    # 'payment gateway timeout'
found.groupdict()   # {'date': '2026-03-20', 'time': '10:15:02', 'level': 'ERROR', 'message': '...'}
```

| Частина шаблону | Що захопила |
|---|---|
| `(?P<date>\d{4}-\d{2}-\d{2})` | `2026-03-20` |
| пробіл | пробіл |
| `(?P<time>[\d:]+)` | `10:15:02` — цифри й двокрапки, скільки є |
| `(?P<level>[A-Z]+)` | `ERROR` — великі літери до пробілу |
| `(?P<message>.*)` | усе, що лишилось |

Якщо рядок не підходить, `fullmatch` повертає `None` — тому результат завжди перевіряють перед `found["level"]`.

## search, match чи fullmatch

Для **перевірки формату** потрібен саме `fullmatch`: `re.match(r"\d{4}", "2026abc")` знайде збіг на початку і скаже «так». Навіть `re.match(r"\d{4}$", "2026\n")` поверне збіг, бо `$` дозволяє один перенос рядка в кінці, а `fullmatch` — ні.

## Жадібні й ледачі повтори

```python
re.findall(r"<.+>", "<b>sale</b>")     # ['<b>sale</b>'] — .+ захоплює якомога більше
re.findall(r"<.+?>", "<b>sale</b>")    # ['<b>', '</b>'] — +? якомога менше
```

## sub із функцією

Замість рядка-заміни можна передати функцію: вона отримує `Match` і повертає текст.

```python
re.sub(r"\d+", lambda found: str(int(found[0]) * 2), "2 items, 3 boxes")   # '4 items, 6 boxes'
re.sub(r"(\w+)@", r"\1 at ", "anna@example.com")                          # 'anna at example.com'
```

`\1` у рядку-заміні — посилання на першу групу.

## Прапорці і читабельність

```python
CODE = re.compile(
    r"""
    (?P<prefix>[A-Z]{3})   # три великі літери
    -
    (?P<number>\d{6})      # шість цифр
    """,
    re.VERBOSE,
)
re.search(r"error", "Payment ERROR", re.IGNORECASE)   # знайде
```

`re.VERBOSE` дозволяє пробіли й коментарі в шаблоні, `re.IGNORECASE` — без різниці регістру.

## Коли regex не потрібен

- JSON — `json.loads`, HTML — HTML-парсер, URL — `urllib.parse`, дати — `datetime.strptime`.
- Email «за всіма правилами RFC» шаблоном не перевірити; на практиці перевіряють простий формат і надсилають лист з підтвердженням.
- Простий пошук підрядка — `"ERROR" in line`, `line.startswith("GET")` — швидше й зрозуміліше.

## Типові помилки

- Шаблон без `r` — `\b` у звичайному рядку стає символом backspace.
- `re.match` або `search` для перевірки формату замість `fullmatch`.
- Неекранована крапка: `example.com` збігається і з `exampleXcom`.
- Жадібне `.*` захоплює забагато.
- Звернення до групи, коли збігу немає: `None["level"]` → `TypeError`.

## Підсумок

- Шаблони — сирі рядки `r"..."`.
- `fullmatch` — перевірка формату, `search` — пошук будь-де, `findall` / `finditer` — усі збіги, `sub` — заміна, `split` — розбиття.
- Групи `( )` і `(?P<name> )` витягують частини; `groupdict()` — словник.
- `+?` / `*?` — ледачі повтори; `re.VERBOSE` — читабельні шаблони; `compile` — для частого використання.
- Для JSON, HTML, URL і дат є спеціальні парсери.
