# Tech check: Python backend

Це підсумкова перевірка блоку розробки: питання, які реально звучать на технічній співбесіді Junior Python Developer, — про тестування, мову, алгоритми, бази, FastAPI, Django, async і розгортання. Блок вважається пройденим, коли ти складеш tech check.

## Як проходить сесія

1. 12 випадкових питань з банку — рівномірно з кожного модуля, тема за темою.
2. На кожне — близько 2 хвилин. Відповідай **уголос**, ніби навпроти сидить інтерв'юер.
3. Відкриваєш еталонну відповідь і відмічаєш ключові пункти, які ти **справді сказав(ла)**.
4. Прохідний бал — 80%. Повторна спроба — новий набір питань.

## Як відповідати

- **Що це → приклад → де важливо → пастка** — та сама схема, що й у першому уроці модуля.
- **Компроміс** замість «правильної відповіді»: «JWT, бо…, але мінус — відкликання», «`selectinload`, бо…, а `joinedload` — коли…».
- **Приклади зі своїх задач**: LRU-кеш, ендпоінт з `dependency_overrides`, N+1 з `selectinload`, `TaskGroup` для дашборда, `/ready` з `503`, `.dockerignore`.
- **Не вигадуй.** Не пам'ятаєш назву параметра — опиши поведінку й скажи, де подивився(лася) б.

> [!TIP]
> Найчастіші уточнення: «а як ти це протестуєш?», «що буде при одночасних запитах?», «а якщо база недоступна?», «чому не async?», «скільки це запитів до бази?». Після кожної відповіді сам(а) став собі одне з них.
