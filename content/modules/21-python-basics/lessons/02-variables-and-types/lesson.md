# Змінні та типи даних

Змінна — це **ім'я**, яке посилається на значення. У тестах змінні тримають усе: логін, очікувану суму, статус-код відповіді.

```python
username = "qa@gadgetly.test"
expected_total = 5570
is_logged_in = False
```

Знак `=` — це **присвоєння**: «нехай `username` означає цей рядок». Порівняння пишеться `==` (урок 3).

## Імена змінних

- літери, цифри і `_`, не можна починати з цифри;
- регістр важливий: `total` і `Total` — різні змінні;
- у Python прийнято **snake_case**: `expected_total`, `max_retries`;
- константи, які не змінюються, пишуть ВЕЛИКИМИ: `BASE_URL = "https://api.gadgetly.test"`.

Змінній можна присвоїти нове значення, навіть іншого типу — Python **динамічно типізований**:

```python
attempts = 0
attempts = attempts + 1   # тепер 1
```

## Основні типи

| Тип | Приклад | Для чого |
|---|---|---|
| `int` | `42`, `-1`, `0` | цілі числа: кількість, статус-код |
| `float` | `19.99`, `0.5` | дробові числа: ціни, відсотки |
| `str` | `"passed"`, `'Kyiv'` | текст |
| `bool` | `True`, `False` | так / ні (з великої літери!) |
| `None` | `None` | «значення немає» |

Тип значення показує `type()`:

```python
type(42)        # <class 'int'>
type("42")      # <class 'str'>
type(None)      # <class 'NoneType'>
```

> [!WARNING]
> `42` і `"42"` — різні значення. `42 == "42"` дає `False`, а `"42" + 1` — помилку `TypeError`.

## Перетворення типів

Усе, що приходить з поля форми, з файлу чи URL, — це **рядки**. Перед обчисленнями їх перетворюють:

```python
int("3")          # 3
float("19.99")    # 19.99
str(5570)         # "5570"
int(" 7 ")        # 7 — пробіли по краях int() пропускає
int("3.5")        # ValueError: invalid literal for int()
float("abc")      # ValueError
```

`bool()` перетворює значення на `True`/`False`: порожні значення (`0`, `""`, `None`) — `False`, решта — `True`. Про це детальніше в уроці про умови.

> [!QA]
> Помилка `ValueError` при `int("abc")` — це саме те, що має обробляти застосунок, коли користувач вводить у поле «кількість» літери. Тестувальник перевіряє, що програма не падає, а показує зрозуміле повідомлення.

## Кілька значень і `repr()`

```python
passed, failed = 12, 1      # два присвоєння одразу
print(repr("passed"))       # 'passed' — з лапками: видно, що це рядок
print(repr(5))              # 5
```

`repr()` показує значення «як у коді». Тести pytest саме так показують значення в повідомленнях про помилку: `assert '5' == 5`.

## Розбір крок за кроком

Простежимо, що відбувається з кожною змінною:

```python
price = "450"
quantity = "2"
total = float(price) * int(quantity)
label = "Total: " + str(total)
```

| Рядок | Змінна | Значення | Тип |
|---|---|---|---|
| 1 | `price` | `"450"` | `str` |
| 2 | `quantity` | `"2"` | `str` |
| 3 | `total` | `900.0` | `float` — `float * int` дає `float` |
| 4 | `label` | `"Total: 900.0"` | `str` |

Саме таку таблицю варто подумки будувати, коли код поводиться дивно: на якому рядку значення стало не тим, що ти очікував?

## Звідки беруться рядки

На своєму комп'ютері програма може попросити дані в користувача:

```python
age = input("Your age: ")      # користувач вводить 25
print(type(age))               # <class 'str'> — завжди рядок!
age = int(age)
```

`input()` **завжди** повертає рядок — як і поле форми на сайті. У задачах курсу дані приходять параметрами функції, але правило те саме.

## Типові помилки

- `"5" + 5` — `TypeError`: рядок і число не складаються. Спершу перетвори: `int("5") + 5` або `"5" + str(5)`.
- `int("3.5")` — `ValueError`: для дробових — `float("3.5")`.
- `"10" < "9"` — `True`! Рядки порівнюються посимвольно (`"1"` менше за `"9"`), а не як числа. Числа з форми спершу перетворюй.
- `Total = 5` і `total` — різні змінні: одруківка в регістрі дає `NameError`.

> [!QA]
> Порівняння чисел як рядків — реальний баг сортування: «від дешевих до дорогих» ставить 1000 перед 999. Це варто перевіряти на будь-якій таблиці з числами.

## Підказки типів

У задачах ти бачитимеш таке:

```python
def total_price(price: str, quantity: str) -> float:
```

`: str` і `-> float` — **підказки типів** (type hints): документація для людей і редактора. Python їх не перевіряє під час виконання. Детально — в модулі «Functions, Modules & Errors».

## Підсумок

- Змінна — ім'я для значення; імена в snake_case, константи — ВЕЛИКИМИ.
- Основні типи: `int`, `float`, `str`, `bool`, `None`; `type()` показує тип.
- Дані з форм і файлів — рядки: перетворюй через `int()`, `float()`, `str()`.
- Невдале перетворення дає `ValueError` — це типова причина багів.
