# Рядки та f-strings

Тестувальник постійно працює з текстом: email, URL, повідомлення про помилки, назви тестів, логи. У Python текст — це тип `str`.

## Індекси і зрізи

Рядок — послідовність символів. Кожен символ має **індекс** від `0`; від'ємні індекси рахують з кінця.

```python
code = "QA-1042"
code[0]       # 'Q'
code[-1]      # '2' — останній символ
len(code)     # 7
```

**Зріз** `[start:end]` бере символи від `start` до `end` **не включно**:

```python
code[0:2]     # 'QA'
code[3:]      # '1042' — до кінця
code[-4:]     # '1042' — останні 4 символи
```

> [!TIP]
> Зріз ніколи не падає з помилкою: `"QA"[0:100]` просто дасть `'QA'`. А звертання до неіснуючого індексу `"QA"[5]` — це `IndexError`.

## Методи рядків

| Метод | Що робить | Приклад → результат |
|---|---|---|
| `lower()` / `upper()` | регістр | `"QA@Test.com".lower()` → `'qa@test.com'` |
| `strip()` | прибирає пробіли по краях | `"  Kyiv \n".strip()` → `'Kyiv'` |
| `replace(a, b)` | заміна | `"1 000".replace(" ", "")` → `'1000'` |
| `split(sep)` | розбити на список | `"a,b,c".split(",")` → `['a', 'b', 'c']` |
| `"sep".join(list)` | склеїти список | `", ".join(["a", "b"])` → `'a, b'` |
| `startswith` / `endswith` | початок / кінець | `"test_login".startswith("test_")` → `True` |
| `in` | містить підрядок | `"Not found" in message` → `True` / `False` |
| `count`, `find` | кількість / позиція | `"a-b-c".count("-")` → `2` |

Рядки **незмінні**: методи не змінюють рядок, а повертають новий.

```python
email = "  QA@Gadgetly.Test "
email.strip()          # повертає новий рядок
print(email)           # '  QA@Gadgetly.Test ' — оригінал той самий
email = email.strip().lower()   # зберегти результат — присвоїти знову
```

> [!QA]
> Пробіли по краях і регістр — класичні баги форм: `"qa@test.com "` не знаходить користувача. Нормалізація (`strip().lower()`) — те, що варто перевіряти на кожному полі email.

## f-strings

**f-string** — рядок з префіксом `f`, у який вставляються значення у фігурних дужках:

```python
name, passed, total = "login", 12, 13
f"{name}: {passed}/{total} passed"          # 'login: 12/13 passed'
```

Після `:` можна вказати формат:

```python
f"{92.307692:.1f}%"      # '92.3%' — 1 знак після коми
f"{5570:,} UAH"          # '5,570 UAH' — розділювач тисяч
f"{7:03}"                # '007' — доповнити нулями до 3 цифр
f"{'OK':>6}"             # '    OK' — вирівняти праворуч у 6 символів
```

Усередині дужок — будь-який вираз: `f"{passed / total * 100:.1f}%"`.

## Спеціальні символи

`\n` — новий рядок, `\t` — табуляція, `\"` — лапка всередині рядка. Багаторядковий текст — у потрійних лапках `"""…"""`.

## Підсумок

- Індекси від 0, `-1` — останній; зріз `[start:end]` не включає `end`.
- Методи `lower`, `strip`, `replace`, `split`, `join`, `startswith`, `in` — щоденні інструменти.
- Рядки незмінні: результат методу треба зберегти.
- f-string: `f"{value}"`, формати `:.1f`, `:,`, `:03`.
