# Оператори і вирази

Вираз — це все, що обчислюється у значення: `2 + 3`, `price * quantity`, `status == "passed"`. Тести складаються з виразів: «обчисли очікуване» і «порівняй з фактичним».

## Арифметика

| Оператор | Що робить | Приклад | Результат |
|---|---|---|---|
| `+` `-` `*` | додавання, віднімання, множення | `5570 - 275` | `5295` |
| `/` | ділення — **завжди** `float` | `10 / 4` | `2.5` |
| `//` | цілочисельне ділення (вниз) | `10 // 4` | `2` |
| `%` | остача від ділення | `10 % 4` | `2` |
| `**` | степінь | `2 ** 10` | `1024` |

```python
items, per_page = 25, 10
full_pages = items // per_page      # 2
left = items % per_page             # 5 — ще одна неповна сторінка
```

> [!QA]
> `//` і `%` — улюблене місце для off-by-one багів: «25 товарів по 10 на сторінці — скільки сторінок?» Правильно 3, а `25 // 10` дає 2. Тестуй межі: 0, рівно 10, 11.

Скорочені присвоєння: `attempts += 1` — те саме, що `attempts = attempts + 1`. Так само `-=`, `*=`.

## Округлення

```python
round(59.970000000000006, 2)   # 59.97
round(2.5)                     # 2 — «банківське» округлення до парного!
```

> [!WARNING]
> Дробові числа зберігаються неточно: `0.1 + 0.2 == 0.3` дає `False`. Гроші в реальних системах часто рахують у копійках (`int`). У тестах дробові порівнюють з допуском — `pytest.approx` (модуль pytest).

## Порівняння

`==` `!=` `<` `<=` `>` `>=` повертають `True` або `False`:

```python
status_code = 404
status_code == 200        # False
status_code != 200        # True
```

Python уміє **ланцюжки порівнянь** — ідеально для меж діапазону:

```python
age = 18
18 <= age <= 99           # True — те саме, що 18 <= age and age <= 99
```

## Логічні оператори

| Оператор | Значення |
|---|---|
| `a and b` | `True`, лише якщо обидва `True` |
| `a or b` | `True`, якщо хоч одне `True` |
| `not a` | заперечення |

```python
is_member = True
subtotal = 2500
free_delivery = is_member or subtotal >= 10000      # True
```

## Пріоритет

Спершу `**`, потім `* / // %`, потім `+ -`, потім порівняння, потім `not`, `and`, `or`. Якщо сумніваєшся — **став дужки**: `(price - discount) * quantity` читається однозначно.

## Розбір: секунди → хвилини і секунди

Звіт показує тривалість тесту як `2 min 15 s`, а система зберігає секунди. Розберемо крок за кроком для `135`:

```python
seconds = 135
minutes = seconds // 60      # 135 // 60 = 2 — скільки повних хвилин
rest = seconds % 60          # 135 % 60 = 15 — що лишилося
```

| Значення `seconds` | `seconds // 60` | `seconds % 60` | Результат |
|---|---|---|---|
| `135` | `2` | `15` | `2 min 15 s` |
| `60` | `1` | `0` | `1 min 0 s` — межа |
| `59` | `0` | `59` | `0 min 59 s` — межа |
| `0` | `0` | `0` | `0 min 0 s` |

Зверни увагу на рядки-межі: саме на них перевіряють такі обчислення. Ще один частий прийом з `%`: `n % 2 == 0` — число парне.

## Типові помилки

- `/` замість `//`: `7 / 2` дає `3.5`, а не `3`.
- `=` замість `==` в умові: `if status = 200:` — `SyntaxError`.
- `a or b and c` — `and` виконується раніше за `or`. Став дужки, щоб не гадати.
- `round(x)` для грошей у звіті може дати несподіване `2.5 → 2`. Якщо правило — «копійки відкидаємо», бери `//`.

## Підсумок

- `/` завжди дає `float`; `//` — ціле вниз; `%` — остача.
- `round(x, 2)` для відображення; дробові порівнюють з допуском.
- Ланцюжок `low <= x <= high` — найкращий спосіб перевірити діапазон.
- `and`, `or`, `not`; при сумнівах — дужки.
