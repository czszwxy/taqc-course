# Python для тестувальника і перша програма

Python — одна з найпопулярніших мов в автоматизації тестування. Причина проста: код читається майже як англійський текст, а для тестувальника є готові інструменти:

- **pytest** — найпопулярніший фреймворк для тестів у Python;
- **Playwright for Python** — той самий Playwright, що ти, можливо, вже бачив у TypeScript;
- **requests** — HTTP-запити для API-тестів одним рядком;
- робота з даними: JSON, CSV, бази даних, файли логів.

> [!QA]
> Багато вакансій QA Automation вимагають саме Python. Якщо ти вже знаєш TypeScript, Python здасться знайомим: ті самі ідеї (змінні, функції, цикли), але менше дужок і крапок з комою.

## Як Python виконує програму

Програма на Python — це звичайний текстовий файл з розширенням `.py`. Python читає його **згори донизу** і виконує рядок за рядком.

```python
print("Test run started")
print("Checking login page...")
print("Done!")
```

```text
Test run started
Checking login page...
Done!
```

`print()` — вбудована функція, яка виводить текст. Текст у лапках — це **рядок** (`str`). Лапки можна брати одинарні або подвійні: `'QA'` і `"QA"` — одне й те саме.

`print()` приймає кілька значень через кому і ставить між ними пробіл:

```python
print("Passed:", 12)      # Passed: 12
print()                   # порожній рядок
```

## Коментарі

Усе після `#` до кінця рядка — **коментар**. Python його ігнорує, а людям він пояснює код.

```python
# Перевіряємо сторінку логіну
print("login: ok")  # коментар може стояти і після коду
```

## Відступи — частина синтаксису

У Python **відступи мають значення**. Блок коду (тіло функції, `if`, циклу) позначається відступом у **4 пробіли** після рядка з двокрапкою `:`.

```python
def say_hello():
    print("Hello!")     # 4 пробіли — це тіло функції
    print("Ready.")

say_hello()
```

Якщо відступ зламаний, Python навіть не почне виконувати програму:

```text
IndentationError: expected an indented block after function definition on line 1
```

> [!WARNING]
> Не змішуй пробіли й табуляцію. Редактори (VS Code і редактор у цьому курсі) самі вставляють 4 пробіли, коли натискаєш Tab.

## Перша функція

Майже всі задачі в курсі — це **функції**: ти пишеш функцію, а приховані тести її викликають з різними даними. Детально функції — в уроці 7, а поки достатньо такого шаблону:

```python
def greet(name):
    return "Hello, " + name + "!"

print(greet("QA"))   # Hello, QA!
```

- `def` — оголошення функції, `greet` — її назва, `name` — параметр;
- `return` — значення, яке функція **повертає** тому, хто її викликав;
- `"Hello, " + name` — склеювання (конкатенація) рядків.

> [!IMPORTANT]
> `print()` лише **показує** значення на екрані, а `return` **повертає** його з функції. Тести перевіряють те, що функція повертає. Функція без `return` повертає `None` — і тест упаде.

## Як запускати код

**Тут, у курсі.** У задачах справжній Python працює прямо в браузері. Кнопка **Run** виконує твій файл і показує вивід `print()`, кнопка **Check** запускає приховані тести.

**На своєму комп'ютері** (знадобиться з модуля pytest):

1. Встанови Python з python.org. На Windows познач **Add python.exe to PATH**.
2. Перевір у терміналі:

```bash
python --version      # або на Windows: py --version
```

3. Створи файл `hello.py` і запусти:

```bash
python hello.py
```

4. **Інтерактивний режим (REPL)**: команда `python` без файлу відкриває консоль `>>>`, де кожен рядок виконується одразу — зручно, щоб швидко щось перевірити. Вихід — `exit()`.

## Як працювати із задачами курсу

1. Прочитай умову і приклади — вони показують, що функція має **повертати**.
2. У стартовому коді вже є рядок `def ...` і `pass` — «заглушка», яка нічого не робить. Заміни `pass` своїм кодом.
3. **Run** — щоб подивитися, що друкує твій код. **Check** — приховані тести викликають твою функцію з різними даними.
4. Якщо тест упав, під ним є підказка і рядок на кшталт `assert 'login' == 'Login'`: зліва — що повернула твоя функція, справа — що очікували.

## Типові помилки на старті

| Що написано | Що скаже Python | Як виправити |
|---|---|---|
| `print(Hello)` | `NameError: name 'Hello' is not defined` | текст — у лапках: `print("Hello")` |
| `Print("Hi")` | `NameError: name 'Print' is not defined` | регістр важливий: `print` |
| `def check(status)` без `:` | `SyntaxError: expected ':'` | двокрапка наприкінці рядка `def` |
| тіло функції без відступу | `IndentationError` | 4 пробіли перед кожним рядком тіла |
| `print(result)` замість `return result` | помилки немає, але тест падає з `None` | функція має **повертати** значення |
| `true`, `false` | `NameError` | у Python — `True`, `False` з великої літери |

> [!TIP]
> Помилка — не провал, а підказка. Перший рядок знизу в повідомленні каже, **що** не так, а рядок над ним — **де**.

## Підсумок

- Python — популярна мова для автотестів: pytest, Playwright, requests.
- Програма виконується згори донизу; `print()` виводить текст, `#` — коментар.
- Відступ у 4 пробіли після `:` позначає блок коду — це частина синтаксису.
- Функція: `def назва(параметри):`, тіло з відступом, `return` повертає результат.
- Тести перевіряють те, що функція **повертає**, а не те, що вона друкує.
