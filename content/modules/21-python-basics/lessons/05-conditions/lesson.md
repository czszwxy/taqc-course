# Умови

Умови — це правила продукту в коді: «якщо сума від 10 000 — доставка безкоштовна», «якщо статус 401 — показати форму входу». Тестувальник, який читає умови, одразу бачить, де межі і які гілки треба перевірити.

## if / elif / else

```python
def http_status_class(code):
    if 200 <= code <= 299:
        return "success"
    elif 300 <= code <= 399:
        return "redirect"
    elif 400 <= code <= 499:
        return "client error"
    else:
        return "other"
```

- після умови — двокрапка `:`, тіло — з відступом;
- `elif` («else if») перевіряється, лише якщо попередні умови були хибні;
- `else` спрацьовує, коли не підійшла жодна умова;
- Python перевіряє умови **згори донизу** і виконує **першу** істинну гілку.

> [!WARNING]
> Порядок має значення. Якщо першою поставити `if code >= 200:`, то 404 і 500 теж потраплять у «success». Від вузьких умов — до широких.

## Truthy і falsy

У `if` можна писати не лише `True`/`False`, а будь-яке значення. **Хибними** (falsy) вважаються: `False`, `None`, `0`, `0.0`, `""` (порожній рядок), порожні колекції `[]`, `{}`. Усе інше — **істинне** (truthy).

```python
name = ""
if not name:
    print("Name is required")     # спрацює: порожній рядок — falsy

if name.strip():                  # рядок лише з пробілів після strip() стає порожнім
    print("Name is filled")
```

> [!QA]
> «Поле лише з пробілів» — класичний баг валідації: `"   "` — truthy, тому `if name:` пропускає його. Правильна перевірка — `if not name.strip():`.

## Порівняння з None

```python
if result is None:
    print("no result")
```

Для `None` прийнято писати `is None` / `is not None`, а не `== None`.

## Оператор in

```python
method = "courier"
if method in ("pickup", "post", "courier"):
    print("known delivery method")
```

`in` перевіряє, чи є значення в наборі — читається краще, ніж три `or`.

## Ранній return

Замість глибокої вкладеності функція може повернути результат одразу, щойно все ясно:

```python
def delivery_fee(subtotal, method):
    if method == "pickup":
        return 0
    if method == "post":
        return 70
    if method == "courier":
        if subtotal >= 10000:
            return 0
        return 150
    return None    # невідомий спосіб доставки
```

Кожна гілка — окремий сценарій для тесту: pickup, post, courier нижче межі, courier рівно на межі, невідомий метод.

## Тернарний вираз

Для простого вибору з двох значень є коротка форма:

```python
label = "free" if fee == 0 else f"{fee} UAH"
```

Не вкладай їх одне в одне — для складної логіки краще звичайний `if`.

## Підсумок

- `if` / `elif` / `else`: перевірка згори донизу, виконується перша істинна гілка.
- Порядок умов — від вузьких до широких; межі — через `<=` / `>=`.
- Falsy: `False`, `None`, `0`, `""`, порожні колекції; рядок з пробілами — truthy.
- `is None`, `in (...)`, ранній `return`; кожна гілка — тест-кейс.
