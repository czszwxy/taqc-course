# JSON

**JSON** (JavaScript Object Notation) — найпоширеніший формат даних в API. Його легко читає і людина, і програма. API-тестувальник читає JSON щодня: перевіряє поля, значення і **типи**.

## Синтаксис

```json
{
  "id": 1003,
  "status": "created",
  "paid": false,
  "coupon": null,
  "total": 998.5,
  "items": [
    { "productId": 1, "name": "Wireless Mouse M2", "quantity": 2 }
  ],
  "customer": { "id": 42, "email": "qa@gadgetly.test" }
}
```

| Тип | Приклад | Примітка |
|---|---|---|
| **string** | `"created"` | лише **подвійні** лапки |
| **number** | `1003`, `998.5`, `-1` | без лапок, без нулів на початку (`08` — помилка) |
| **boolean** | `true`, `false` | малими літерами |
| **null** | `null` | «значення немає» |
| **array** | `[1, 2, 3]` | впорядкований список у `[ ]` |
| **object** | `{ "key": value }` | пари ключ-значення у `{ }`; ключі — рядки в лапках |

## Типові помилки синтаксису

- одинарні лапки: `{'name': 'Mouse'}` ❌
- ключ без лапок: `{name: "Mouse"}` ❌
- кома після останнього елемента: `{"a": 1,}` ❌
- коментарі `// …` ❌ (у JSON їх немає)
- `True`, `NULL`, `undefined` ❌

> [!TIP]
> Невалідний JSON у запиті — хороший негативний тест: API має відповісти **400** з поясненням, а не 500.

## Шляхи до значень

Щоб говорити про конкретне поле, використовують **шлях**:

| Шлях | Значення в прикладі вище |
|---|---|
| `status` | `"created"` |
| `items[0].name` | `"Wireless Mouse M2"` (нумерація масиву з **0**) |
| `items.length` | `1` |
| `customer.email` | `"qa@gadgetly.test"` |

Ці самі шляхи ти писатимеш в автотестах: `expect(body.items[0].quantity).toBe(2)`.

## Тип — це теж вимога

| Відповідь API | Проблема |
|---|---|
| `"quantity": "2"` | рядок замість числа: `"2" + 1` у JavaScript дасть `"21"` |
| `"price": "499 UAH"` | число змішане з валютою — неможливо порахувати суму |
| `"total": 998.4999999` | проблеми округлення грошей |
| `"zip": 1001` | поштовий індекс `01001` втратив нуль — має бути рядком |
| `"items": null` замість `[]` | клієнт впаде на `items.length` |
| поле відсутнє замість `null` | чи це «немає даних», чи «забули повернути»? |

> [!QA]
> Домовленість про структуру відповіді (поля, типи, обов'язковість) називають **схемою** (JSON Schema). API-тести часто перевіряють відповідь на відповідність схемі — до цього ти повернешся в модулі 17.

## Підсумок

- JSON = object `{}`, array `[]`, string `""`, number, boolean, null.
- Лише подвійні лапки, без ком у кінці, без коментарів.
- Шлях `items[0].price` — мова, якою говорять про поля.
- Перевіряй не лише значення, а й **типи** та відсутні поля.
