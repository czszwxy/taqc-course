# Пошук і сортування

Знайти запис і впорядкувати записи — дві найчастіші операції з даними. Бази даних роблять це за тебе (індекси, `ORDER BY`), але в коді застосунку, на співбесіді і при обробці файлів ці алгоритми потрібні напряму.

## Лінійний і бінарний пошук

Лінійний пошук перебирає елементи по черзі — `O(n)`, підходить для будь-яких даних. Якщо дані **відсортовані**, можна діяти як зі словником на папері: відкрити посередині й відкинути половину.

```python
def contains(sorted_values, target):
    low, high = 0, len(sorted_values) - 1
    while low <= high:
        middle = (low + high) // 2
        if sorted_values[middle] == target:
            return True
        if sorted_values[middle] < target:
            low = middle + 1           # шукане правіше
        else:
            high = middle - 1          # шукане лівіше
    return False
```

## Розбір: шукаємо 42

`[3, 8, 15, 23, 42, 57, 61, 90]`, індекси 0–7:

| Крок | low | high | middle → значення | Рішення |
|---|---|---|---|---|
| 1 | 0 | 7 | 3 → 23 | 23 < 42 → `low = 4` |
| 2 | 4 | 7 | 5 → 57 | 57 > 42 → `high = 4` |
| 3 | 4 | 4 | 4 → 42 | знайдено |

Кожен крок ділить діапазон навпіл: для мільйона елементів — не більше ~20 кроків (`O(log n)`). Пастки — у межах: `low <= high` (а не `<`), `middle + 1` / `middle - 1` (інакше цикл може зависнути на одному елементі).

## bisect: бінарний пошук зі стандартної бібліотеки

```python
import bisect

thresholds = [0, 1000, 5000, 20000]              # межі рівнів знижки
bisect.bisect_right(thresholds, 7300) - 1        # 2 — рівень для суми 7300
bisect.bisect_left([10, 20, 20, 30], 20)         # 1 — перша позиція, куди можна вставити 20
bisect.insort(sorted_ids, 1005)                  # вставити, зберігши порядок
```

`bisect_left` дає першу позицію, де значення ≥ шуканого («нижня межа»), `bisect_right` — першу позицію, де значення > шуканого.

## Сортування в Python

`sorted(items)` повертає новий список, `items.sort()` сортує на місці. Обидва — **Timsort**: `O(n log n)`, швидкий на частково відсортованих даних і **стабільний** — елементи з однаковим ключем зберігають взаємний порядок.

```python
sorted(orders, key=lambda order: order["total"], reverse=True)   # від найдорожчого
sorted(users, key=lambda user: (user["city"], user["name"]))      # кілька ключів кортежем
```

## Кілька ключів у різних напрямках

Кортеж-ключ сортує все в одному напрямку. Якщо треба «за статусом за зростанням, а всередині — від найновіших», зручно використати стабільність: сортувати **кілька разів, від найменш важливого ключа до найважливішого**:

```python
result = sorted(tickets, key=lambda t: t["created_at"], reverse=True)   # другорядне
result.sort(key=lambda t: t["priority"])                                 # головне — останнім
```

Другий прохід упорядковує за пріоритетом, а всередині однакових пріоритетів зберігає порядок з першого проходу. `reverse=True` теж зберігає стабільність.

## Як сортують: ідея merge sort

Сортування злиттям ділить список навпіл, рекурсивно сортує половини і **зливає** два відсортовані списки в один: порівнює перші елементи, забирає менший, повторює. Злиття — `O(n)`, рівнів поділу — `log n`, разом `O(n log n)`. Простіші алгоритми (бульбашкою, вставками) — `O(n²)`, їх пишуть хіба що на співбесіді. У роботі — `sorted`.

## Топ-k без повного сортування

```python
import heapq

heapq.nlargest(3, products, key=lambda p: p["sales"])   # 3 бестселери
```

Для невеликого `k` це швидше за сортування всього списку: `O(n log k)`.

## Типові помилки

- Бінарний пошук на **невідсортованих** даних — тихо повертає неправильний результат.
- `while low < high` з `high = len - 1` — пропускає останній елемент; `low = middle` — нескінченний цикл.
- `items = items.sort()` — `sort` повертає `None`.
- Сортування рядків з числами: `"100" < "20"`; ключ має бути числом (`key=int`).
- Кортеж-ключ з мінусом для рядків (`-name`) — помилка; для різних напрямків — кілька стабільних проходів.

## Підсумок

- Бінарний пошук — `O(log n)` на відсортованих даних; уважно з межами.
- `bisect_left` / `bisect_right` — готові нижня й верхня межі, `insort` — вставка з порядком.
- `sorted` / `sort` — Timsort, `O(n log n)`, стабільний; `key`, `reverse`, кортежі.
- Різні напрямки ключів — кілька проходів від другорядного до головного.
- Злиття двох відсортованих списків — `O(n + m)`; топ-k — `heapq.nlargest`.
