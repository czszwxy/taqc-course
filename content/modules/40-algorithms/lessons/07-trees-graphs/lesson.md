# Дерева та графи

**Дерево** — дані з ієрархією: категорії товарів, коментарі з відповідями, структура папок, організаційна схема. **Граф** — дані зі зв'язками без єдиної ієрархії: станції метро, друзі в соцмережі, залежності пакетів, порядок міграцій бази даних. Дерево — окремий випадок графа без циклів, де в кожного вузла (крім кореня) рівно один батько.

## Терміни

| Термін | Значення |
|---|---|
| вершина (node), ребро (edge) | об'єкт і зв'язок між двома об'єктами |
| корінь, діти, лист | вершина без батька; вершини рівнем нижче; вершина без дітей |
| глибина | кількість рівнів від кореня |
| напрямлений граф | ребро має напрямок: «A залежить від B» ≠ «B залежить від A» |
| цикл | шлях, що повертається в початкову вершину |

## Як зберігають у Python

```python
catalog = {"name": "All", "children": [
    {"name": "Audio", "children": [{"name": "Headphones"}, {"name": "Speakers"}]},
    {"name": "Computers", "children": [{"name": "Laptops"}]},
]}

metro = {                        # список суміжності: вершина → сусіди
    "Vokzalna": ["Universytet"],
    "Universytet": ["Vokzalna", "Teatralna"],
    "Teatralna": ["Universytet", "Khreshchatyk"],
    "Khreshchatyk": ["Teatralna"],
}
```

## Обхід у глибину (DFS)

Заходимо в першу дитину, потім у її першу дитину — до самого низу, і лише потім повертаємось. Для дерев це природна рекурсія:

```python
def print_tree(node, depth=0):
    print("  " * depth + node["name"])
    for child in node.get("children", []):
        print_tree(child, depth + 1)
```

## Обхід у ширину (BFS)

Спершу всі сусіди, потім сусіди сусідів — рівень за рівнем. Потрібна **черга** і множина **відвіданих**, щоб у графі з циклами не ходити по колу:

```python
from collections import deque


def reachable(graph, start):
    visited = {start}
    queue = deque([start])
    while queue:
        node = queue.popleft()
        for neighbour in graph.get(node, []):
            if neighbour not in visited:
                visited.add(neighbour)
                queue.append(neighbour)
    return visited
```

## Розбір: BFS дає найкоротший шлях за кількістю кроків

Граф: `A → B, E`; `B → C`; `C → D`; `E → D`. Шукаємо шлях з `A` до `D`.

| Крок | Беремо з черги | Нові сусіди (і звідки прийшли) | Черга після |
|---|---|---|---|
| 1 | A | B ← A, E ← A | B, E |
| 2 | B | C ← B | E, C |
| 3 | E | D ← E | C, D |
| 4 | C | (D вже бачили) | D |
| 5 | D | — це ціль | |

Шлях відновлюють «назад» за записами «звідки прийшли»: `D ← E ← A`, тобто `A → E → D` — 2 кроки. DFS пішов би першим сусідом `B` і знайшов `A → B → C → D` — теж шлях, але довший. Тому для «найменше пересадок», «найкоротший ланцюжок знайомств» беруть BFS. (Для графів з вагами — відстанями, цінами — є алгоритм Дейкстри.)

## Топологічний порядок

Залежності пакетів чи міграцій — напрямлений граф «X потребує Y». **Топологічний порядок** — такий порядок вершин, де кожна залежність стоїть раніше за того, хто від неї залежить. У стандартній бібліотеці є готовий інструмент:

```python
from graphlib import TopologicalSorter

needs = {"api": ["db", "auth"], "auth": ["db"], "db": []}
list(TopologicalSorter(needs).static_order())     # ['db', 'auth', 'api']
```

Якщо залежності утворюють цикл (`a` потребує `b`, а `b` — `a`), правильного порядку не існує: `static_order()` кине `graphlib.CycleError` (підклас `ValueError`).

## Типові помилки

- Обхід графа без множини відвіданих — нескінченний цикл на першому ж циклі.
- Позначати вершину відвіданою, лише коли її **виймають** з черги, — вона потрапляє в чергу кілька разів.
- DFS там, де потрібен найкоротший шлях.
- Рекурсивний DFS для дуже глибоких графів — `RecursionError`; рятує власний стек.
- Відсутній ключ у списку суміжності (вершина без сусідів) — `KeyError`; використовуй `graph.get(node, [])`.

## Підсумок

- Дерево — ієрархія без циклів; граф — довільні зв'язки, можливо з циклами й напрямками.
- Представлення: вкладені словники для дерев, словник «вершина → сусіди» для графів.
- DFS — у глибину (рекурсія або стек), BFS — у ширину (черга); обом потрібні відвідані.
- BFS знаходить шлях з найменшою кількістю кроків; шлях відновлюють за записами «звідки прийшли».
- Залежності — топологічний порядок (`graphlib.TopologicalSorter`), цикл — помилка.
