# Термінал: перші кроки

Автотести запускаються з **терміналу**: `npx playwright test`, `npm test`, `git push`. CI-сервер (GitHub Actions) теж просто виконує команди в терміналі, тільки без людини. Тому QA Automation має почуватися в терміналі впевнено. Добра новина: для щоденної роботи вистачає двох десятків команд.

## Термінал і shell

- **Термінал** — вікно, у якому вводять команди (Windows Terminal, вбудований термінал VS Code).
- **Shell** — програма, яка ці команди виконує. На Windows це **PowerShell**, на macOS і Linux — **bash** або **zsh**. На Windows разом із Git встановлюється ще й **Git Bash**.

Більшість базових команд однакові в обох світах: PowerShell розуміє `ls`, `cd`, `pwd`, `cat`, `mkdir`, `rm` як скорочення (aliases) своїх команд.

## Поточна папка і шляхи

Термінал завжди «стоїть» у якійсь папці — це **поточна робоча папка** (working directory). Її видно в запрошенні (prompt):

```text
PS D:\qa-academy>            ← PowerShell: ти в папці D:\qa-academy
olena@laptop:~/projects$     ← bash: ти в ~/projects (~ — домашня папка)
```

**Абсолютний шлях** починається від кореня диска і працює з будь-якої папки: `D:\qa-academy\tests`, `/home/olena/projects`.
**Відносний шлях** рахується від поточної папки:

| Шлях | Значення |
|---|---|
| `tests` або `./tests` | папка `tests` всередині поточної |
| `..` | папка на рівень вище (батьківська) |
| `../reports` | папка `reports` поряд з поточною |
| `.` | поточна папка |

> [!TIP]
> Windows пише шляхи через `\`, а Linux і macOS — через `/`. PowerShell і Node.js розуміють обидва варіанти. У конфігах і коді тестів пиши `/`: так тест запуститься і на CI (Linux).

## Базові команди

| Що зробити | PowerShell | bash |
|---|---|---|
| Де я? | `pwd` | `pwd` |
| Що в папці? | `ls` (`Get-ChildItem`) | `ls`, `ls -la` (з прихованими) |
| Перейти в папку | `cd tests` | `cd tests` |
| На рівень вище | `cd ..` | `cd ..` |
| Створити папку | `mkdir reports` | `mkdir reports` |
| Показати вміст файлу | `cat package.json` (`Get-Content`) | `cat package.json` |
| Копіювати | `cp a.txt b.txt` | `cp a.txt b.txt` |
| Перемістити / перейменувати | `mv old.txt new.txt` | `mv old.txt new.txt` |
| Видалити файл | `rm old.log` | `rm old.log` |
| Очистити екран | `clear` або `cls` | `clear` |

> [!WARNING]
> `rm` видаляє **без кошика**. `rm -rf folder` у bash або `Remove-Item -Recurse -Force folder` у PowerShell видаляє папку з усім вмістом без питань. Перед такою командою перевір `pwd`: чи ти точно там, де думаєш?

## Команда, аргументи, прапорці

```bash
npx playwright test login.spec.ts --headed --workers=1
#   команда         аргумент        прапорці (flags / options)
```

- **аргументи** — над чим працювати (файл, папка);
- **прапорці** починаються з `-` або `--` і змінюють поведінку: `--headed` (показати браузер), `-v` / `--version`.
- `--help` майже в будь-якої програми показує довідку: `npx playwright test --help`.

## Прийоми, що економлять години

- **Tab** доповнює назви файлів і папок. Набери `cd te` і натисни Tab.
- **↑ / ↓** гортають історію команд, тож не треба набирати двічі.
- **Ctrl+C** зупиняє команду, що «зависла» або працює довго (dev-сервер, тести).
- Шляхи з пробілами бери в лапки: `cd "C:\Program Files\nodejs"`.
- У VS Code термінал відкривається через **Ctrl+`** і одразу стоїть у папці проєкту.

## Читаємо помилки

```text
cd: no such file or directory: test       ← папки "test" немає (може, "tests"?)
'npx' is not recognized as an internal …  ← Node.js не встановлений або не в PATH
npm ERR! enoent Could not read package.json  ← ти не в папці проєкту
```

> [!QA]
> Повідомлення про помилку — це «actual result» терміналу. Читай його повністю, а не лише слово «error». У 80% випадків там написано, що не так: не та папка, одрук у назві, програма не встановлена.

**PATH** — список папок, у яких shell шукає програми. «Command not found» / «not recognized» майже завжди означає, що програма не встановлена або її папки немає в PATH. Часто допомагає перезапустити термінал після встановлення.

## Підсумок

- Термінал — вікно, shell — програма, що виконує команди (PowerShell, bash).
- Завжди знай поточну папку (`pwd`). Абсолютний шлях іде від кореня, відносний — від поточної папки (`..` = рівень вище).
- Базові команди: `pwd`, `ls`, `cd`, `mkdir`, `cat`, `cp`, `mv`, `rm`, `clear`.
- Команда + аргументи + прапорці (`--headed`); `--help` показує довідку.
- Tab, ↑ і Ctrl+C економлять час. Помилку читай повністю.
