# Списки

**Список** (`list`) — впорядкована колекція значень. У тестах списки всюди: результати прогону, рядки таблиці, товари в кошику, час відповідей API.

```python
results = ["passed", "failed", "passed"]
times_ms = [120, 85, 340, 95]
empty = []
```

Список може містити будь-які значення, навіть різних типів, але на практиці в одному списку тримають однотипні дані.

## Індекси і зрізи

Так само, як у рядках: індекси з `0`, від'ємні — з кінця, зрізи `[start:end]` без `end`.

```python
times_ms[0]       # 120
times_ms[-1]      # 95
times_ms[1:3]     # [85, 340]
len(times_ms)     # 4
```

На відміну від рядків, список **змінюваний**: `times_ms[0] = 100` замінить перший елемент.

## Змінювати список

| Метод | Що робить |
|---|---|
| `append(x)` | додати в кінець |
| `insert(i, x)` | вставити на позицію `i` |
| `extend(other)` | додати всі елементи іншого списку |
| `remove(x)` | видалити **перше** входження `x` (`ValueError`, якщо немає) |
| `pop()` / `pop(i)` | видалити й повернути останній / `i`-й елемент |
| `clear()` | очистити |

```python
cart = ["mouse"]
cart.append("cable")          # ['mouse', 'cable']
cart.insert(0, "keyboard")    # ['keyboard', 'mouse', 'cable']
last = cart.pop()             # last = 'cable'
```

> [!WARNING]
> Методи `append`, `insert`, `remove`, `sort` змінюють список **на місці** і повертають `None`. `cart = cart.append("x")` — класична помилка: після неї `cart` дорівнює `None`.

## Перевірки й обчислення

```python
"failed" in results        # True
results.count("passed")    # 2
results.index("failed")    # 1 — перший індекс
sum(times_ms)              # 640
min(times_ms), max(times_ms)
```

## Новий список у циклі

Найчастіший шаблон: порожній список до циклу, `append` у циклі. Наприклад, прибрати пробіли з email-ів, які прийшли з форми:

```python
raw = [" qa@example.test", "dev@example.test ", " ops@example.test "]
cleaned = []
for email in raw:
    cleaned.append(email.strip())
```

Крок за кроком:

| Ітерація | `email` | `cleaned` після ітерації |
|---|---|---|
| до циклу | — | `[]` |
| 1 | `" qa@example.test"` | `['qa@example.test']` |
| 2 | `"dev@example.test "` | `['qa@example.test', 'dev@example.test']` |
| 3 | `" ops@example.test "` | `['qa@example.test', 'dev@example.test', 'ops@example.test']` |

Додай `if` перед `append` — і отримаєш **фільтр**: у новий список потраплять лише ті елементи, що проходять умову.

## Список списків

Таблиця з інтерфейсу — це список рядків, а кожен рядок — список комірок:

```python
rows = [
    ["Mouse", "450", "In stock"],
    ["Cable", "150", "Out of stock"],
]
rows[1][2]        # 'Out of stock' — рядок 1, стовпець 2
```

## Посилання і копії

Присвоєння **не копіює** список — обидва імені вказують на той самий об'єкт:

```python
original = ["a", "b"]
alias = original
alias.append("c")
print(original)       # ['a', 'b', 'c'] — змінився і «оригінал»!
```

Копія: `original.copy()`, `list(original)` або `original[:]`.

> [!QA]
> Функція, яка непомітно змінює переданий їй список, — джерело «плаваючих» багів у тестах: один тест змінив спільні тестові дані, і наступний падає. Хелпери для тестів мають повертати **новий** список, а не змінювати вхідний — і це варто перевіряти тестом.

## Типові помилки

- `items = items.append(x)` — тепер `items` дорівнює `None`.
- **Видалення під час перебору:** `for x in items: if ...: items.remove(x)` пропускає елементи, бо список зсувається під циклом. Збирай результат у **новий** список.
- `items[0]` для порожнього списку — `IndexError`. Спершу перевір `if items:`.
- `remove(x)` видаляє лише **перше** входження і падає з `ValueError`, якщо `x` немає.

## Підсумок

- `list` — впорядкований і змінюваний; індекси й зрізи як у рядків.
- `append`, `insert`, `extend`, `remove`, `pop` змінюють список на місці й повертають `None`.
- `in`, `count`, `index`, `sum`, `min`, `max`, `len` — щоденні інструменти.
- Шаблон «порожній список → append у циклі»; з `if` — фільтр.
- Присвоєння не копіює: для копії — `.copy()`, `list(x)` або `x[:]`. Не змінюй список, який перебираєш.
