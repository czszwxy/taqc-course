# Сортування і функції key

Сортування в тестах потрібне двічі: щоб **упорядкувати свої дані** (найповільніші тести вгорі звіту) і щоб **перевірити сортування в продукті** («Сортувати за ціною» справді сортує?).

## sorted() і list.sort()

```python
times = [340, 85, 120]

sorted(times)          # [85, 120, 340] — НОВИЙ список
print(times)           # [340, 85, 120] — оригінал не змінився

times.sort()           # сортує НА МІСЦІ, повертає None
print(times)           # [85, 120, 340]
```

`sorted()` працює з будь-якою колекцією (кортеж, множина, ключі словника) і завжди повертає список. У хелперах для тестів обирай `sorted()` — він не змінює вхідні дані.

За спаданням — `reverse=True`:

```python
sorted(times, reverse=True)     # [340, 120, 85]
```

## Рядки і регістр

Рядки сортуються за кодами символів: **великі літери йдуть перед малими**.

```python
sorted(["banana", "Apple", "cherry"])               # ['Apple', 'banana', 'cherry']
sorted(["banana", "apple", "Cherry"])               # ['Cherry', 'apple', 'banana'] — несподівано!
sorted(["banana", "apple", "Cherry"], key=str.lower) # ['apple', 'banana', 'Cherry']
```

## Параметр key

`key` — функція, яку Python викликає для **кожного** елемента; сортування йде за її результатом:

```python
sorted(["login", "cart", "search"], key=len)    # ['cart', 'login', 'search']
```

## lambda — коротка функція в одному рядку

Щоб не оголошувати окрему функцію через `def`, пишуть `lambda`:

```python
results = [("test_login", 1.25), ("test_cart", 3.4), ("test_search", 0.8)]
sorted(results, key=lambda r: r[1])
# [('test_search', 0.8), ('test_login', 1.25), ('test_cart', 3.4)]
```

`lambda r: r[1]` — те саме, що `def get_duration(r): return r[1]`. Для словників: `key=lambda p: p["price"]`.

## Кілька ключів

Якщо `key` повертає **кортеж**, Python порівнює спершу перший елемент, при рівності — другий:

```python
# за тривалістю за спаданням, при рівності — за назвою за зростанням
sorted(results, key=lambda r: (-r[1], r[0]))
```

Мінус перед числом розвертає порядок лише для цього ключа. Сортування в Python **стабільне**: елементи з рівними ключами зберігають вихідний порядок.

## min і max з key

```python
max(results, key=lambda r: r[1])     # ('test_cart', 3.4) — увесь елемент
min(results, key=lambda r: r[1])[0]  # 'test_search'
```

> [!QA]
> Перевірка сортування в UI: зібрати значення з таблиці у список і порівняти з відсортованою копією — `assert prices == sorted(prices)`. Для «від дорожчих» — `sorted(prices, reverse=True)`. А для назв — пам'ятай про регістр: якщо продукт сортує без урахування регістру, перевіряй з `key=str.lower`.

## Підсумок

- `sorted(x)` — новий список; `x.sort()` — на місці, повертає `None`.
- `reverse=True` — за спаданням.
- `key=функція` — сортування за результатом функції: `str.lower`, `len`, `lambda`.
- Кортеж у `key` — кілька ключів; `-число` розвертає порядок одного ключа.
- `min` / `max` з `key` повертають цілий елемент.
- Перевірка сортування в UI: `values == sorted(values)`.
