# Множини

**Множина** (`set`) — невпорядкована колекція **унікальних** значень. Дублікати зникають автоматично:

```python
tags = {"smoke", "login", "smoke"}
print(tags)              # {'smoke', 'login'} — порядок не гарантовано
ids = set([3, 1, 3, 2])  # {1, 2, 3}
empty = set()            # НЕ {} — це порожній словник!
```

## Операції

```python
s = {"login", "cart"}
s.add("search")
s.discard("cart")        # без помилки, якщо елемента немає
"login" in s             # True — дуже швидко навіть для мільйона елементів
len(s)
```

## Порівняння множин

| Операція | Запис | Результат |
|---|---|---|
| об'єднання | `a \| b` | усі елементи обох |
| перетин | `a & b` | спільні |
| різниця | `a - b` | є в `a`, немає в `b` |
| симетрична різниця | `a ^ b` | є лише в одній з двох |

## Розбір: теги тесту за вимогою і в коді

Вимога каже, що тест має теги `smoke`, `login`, `critical`. У коді тесту — `smoke`, `login`, `regression`. Що не так?

```python
required = {"smoke", "login", "critical"}
actual = {"smoke", "login", "regression"}
```

| Вираз | Результат | Що означає |
|---|---|---|
| `required & actual` | `{'smoke', 'login'}` | збігаються |
| `required - actual` | `{'critical'}` | бракує в коді |
| `actual - required` | `{'regression'}` | зайвий тег |
| `required == actual` | `False` | множини різні |

Одна операція — одна відповідь на питання тесту, і порядок елементів не має значення.

> [!QA]
> Множини — найкоротший спосіб перевірити «у списку ті самі елементи, порядок не важливий»: `set(actual) == set(expected)`. А дві різниці дають зрозуміле повідомлення про те, **що саме** не так. Але пам'ятай: множина губить дублікати, тому окремо перевіряй довжину, якщо дублікати — це баг.

## Дублікати

Чи є дублікати взагалі: `len(items) != len(set(items))` — множина «стискає» повтори, і довжини перестають збігатися.

Щоб дізнатися, **які** значення повторюються, тримай дві множини: «вже бачили» і «бачили більше одного разу». Ідеш списком: якщо значення вже є серед «бачених» — це повтор; потім додаєш його до «бачених».

## Обмеження

- Елементи множини мають бути **незмінними** (числа, рядки, кортежі). Список у множину покласти не можна.
- Порядок не зберігається — для виводу сортуй: `sorted(s)`.

## Типові помилки

- `{}` — порожній **словник**; порожня множина — `set()`.
- `s[0]` — `TypeError: 'set' object is not subscriptable`: у множини немає індексів.
- Порівнювати множини через рядки (`str(s1) == str(s2)`) — порядок друку не гарантований. Порівнюй `s1 == s2`.
- Рахувати кількість через `len(set(items))`, коли повтори важливі, — множина їх «з'їсть».

## Підсумок

- `set` — лише унікальні значення; порожня множина — `set()`.
- `in` для множини — дуже швидкий.
- `|` `&` `-` `^` — об'єднання, перетин, різниця, симетрична різниця.
- Порівняння без урахування порядку: `set(a) == set(b)`; що бракує / що зайве — різниці.
- Множина губить дублікати й порядок: для виводу — `sorted()`.
