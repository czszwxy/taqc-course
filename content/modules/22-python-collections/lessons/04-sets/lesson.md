# Множини

**Множина** (`set`) — невпорядкована колекція **унікальних** значень. Дублікати зникають автоматично:

```python
tags = {"smoke", "login", "smoke"}
print(tags)              # {'smoke', 'login'} — порядок не гарантовано
ids = set([3, 1, 3, 2])  # {1, 2, 3}
empty = set()            # НЕ {} — це порожній словник!
```

## Операції

```python
s = {"login", "cart"}
s.add("search")
s.discard("cart")        # без помилки, якщо елемента немає
"login" in s             # True — дуже швидко навіть для мільйона елементів
len(s)
```

## Порівняння множин

| Операція | Запис | Результат |
|---|---|---|
| об'єднання | `a \| b` | усі елементи обох |
| перетин | `a & b` | спільні |
| різниця | `a - b` | є в `a`, немає в `b` |
| симетрична різниця | `a ^ b` | є лише в одній з двох |

```python
expected = {1001, 1002, 1003}
actual = {1002, 1003, 1004}
expected - actual      # {1001} — бракує
actual - expected      # {1004} — зайве
expected == actual     # False
```

> [!QA]
> Множини — найкоротший спосіб перевірити «у списку ті самі елементи, порядок не важливий»: `set(actual) == set(expected)`. А `expected - actual` і `actual - expected` дають зрозуміле повідомлення про те, **що саме** не так. Але пам'ятай: множина губить дублікати, тому окремо перевіряй довжину, якщо дублікати — це баг.

## Дублікати

Чи є дублікати: `len(items) != len(set(items))`. Які саме — дві множини в циклі:

```python
seen, dups = set(), set()
for item in ["a", "b", "a"]:
    if item in seen:
        dups.add(item)
    seen.add(item)
# dups == {'a'}
```

## Обмеження

- Елементи множини мають бути **незмінними** (числа, рядки, кортежі). Список у множину покласти не можна.
- Порядок не зберігається — для виводу сортуй: `sorted(s)`.

## Підсумок

- `set` — лише унікальні значення; порожня множина — `set()`.
- `in` для множини — дуже швидкий.
- `|` `&` `-` `^` — об'єднання, перетин, різниця, симетрична різниця.
- Порівняння без урахування порядку: `set(a) == set(b)`; що бракує / що зайве — різниці.
- Множина губить дублікати: перевіряй довжину, якщо дублікати важливі.
