# Гнучкі розкладки й container queries

Медіазапити реагують на ширину **екрана**. Але картка рецепта може стояти і в широкій колонці, і у вузькій бічній — екран той самий, а місця різне. Сучасний CSS уміє розкладати елементи **за доступним місцем**: без медіазапитів узагалі або із запитами до **контейнера**.

## min(), max(), clamp()

| Функція | Значення | Приклад |
|---|---|---|
| `min(a, b)` | менше з двох | `width: min(100%, 40rem)` — на всю ширину, але не більше за 40rem |
| `max(a, b)` | більше з двох | `padding: max(1rem, 3vw)` — не менше за 1rem |
| `clamp(min, бажане, max)` | бажане, але в межах | `gap: clamp(1rem, 3vw, 2rem)` |

Усередині можна рахувати. Сторінка рецепта: «на всю ширину мінус поля, але не ширше за 60rem» — один рядок замість `max-width`, `padding` і медіазапиту для полів:

```css
.recipe-page {
  width: min(100% - 2rem, 60rem);
  margin-inline: auto;     /* margin-left і margin-right: auto */
}
```

## Сітка, яка ніколи не вилазить

З модуля CSS: `repeat(auto-fill, minmax(200px, 1fr))` сама вирішує, скільки колонок. Але якщо контейнер вужчий за мінімум колонки, сітка вилазить: `minmax(18rem, 1fr)` у контейнері 260 px дає колонку 288 px.

Фотогалерея:

```css
.gallery {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(min(100%, 14rem), 1fr));
  gap: 1rem;
}
```

`min(100%, 14rem)` означає «14rem, а якщо контейнер вужчий — весь контейнер». Колонок стільки, скільки влізе по 14rem, і жодна колонка не ширша за екран.

`auto-fit` чи `auto-fill`: коли елементів мало (два фото на широкому екрані), `auto-fill` лишає порожні колонки, а `auto-fit` розтягує наявні на всю ширину.

Скільки колонок вийде: `(ширина + gap) / (мінімум + gap)`, округлено вниз. Галерея 900 px, мінімум 14rem = 224 px, gap 16 px: (900 + 16) / (224 + 16) = 3,8 → **3** колонки по (900 − 2 × 16) / 3 ≈ 289 px.

## flex-wrap: елементи переносяться самі

```css
.tags { display: flex; flex-wrap: wrap; gap: 0.5rem; }
.event-filters { display: flex; flex-wrap: wrap; gap: 1rem; }
.event-filters > * { flex: 1 1 12rem; }
```

`flex: 1 1 12rem` — «бажана ширина 12rem, можна розтягувати й стискати». Поки поруч влазять три поля по 12rem, вони стоять у рядку. На телефоні кожне займає весь рядок.

## aspect-ratio і object-fit

```css
.video-frame { width: 100%; aspect-ratio: 16 / 9; }
.avatar { width: 4rem; aspect-ratio: 1; border-radius: 50%; object-fit: cover; }
```

Пропорції без «хаків» з padding: висота рахується від ширини на будь-якому екрані. Для фото різних пропорцій у сітці — `object-fit: cover`: фото заповнює рамку, а зайве обрізається, як на аватарці.

## Container queries

Компонент не знає, де його поставлять. **Container query** питає не «яка ширина екрана?», а «яка ширина мого контейнера?»:

```css
.recipe-slot { container-type: inline-size; }       /* обгортка — контейнер */

.recipe-card { display: grid; gap: 0.75rem; }        /* вузько: фото над текстом */

@container (min-width: 30rem) {                      /* контейнер від 30rem */
  .recipe-card { grid-template-columns: 12rem 1fr; } /* фото ліворуч */
}
```

- `container-type: inline-size` ставиш на **обгортку**: контейнер стилізує своїх нащадків, а не себе.
- `@container (умова)` — як `@media`, але умова про найближчого предка-контейнера.
- Та сама картка горизонтальна в широкому вмісті й вертикальна у вузькій бічній колонці — на одному екрані.
- Одиниці контейнера: `cqi` — 1 % ширини контейнера (`font-size: clamp(1rem, 4cqi, 1.5rem)`).
- Працює в усіх браузерах з 2023 року.

## Коли що

| Задача | Інструмент |
|---|---|
| Сітка однакових карток | `auto-fit` + `minmax(min(100%, …), 1fr)` |
| Поля й теги, що переносяться | `flex-wrap: wrap` + `flex-basis` |
| Ширина сторінки з полями | `min(100% - 2rem, …)` |
| Компонент у різних місцях сторінки | container query |
| Зміна сторінки загалом: меню, бічна колонка, тема | media query |

> [!TIP]
> Чим менше медіазапитів, тим менше меж, на яких щось може зламатися. Спершу спробуй гнучку розкладку, а медіазапит пиши тоді, коли без нього справді не обійтися.

> [!QA]
> Компонент з container query тестують не лише на різних ширинах екрана, а й у різних **місцях**: та сама картка в основному вмісті, у бічній колонці, у модальному вікні. Дві однакові картки на одному екрані можуть виглядати по-різному — і це правильно.

## Підсумок

- `min()`, `max()`, `clamp()` — розміри, що самі тримаються в межах; всередині можна рахувати.
- `repeat(auto-fit, minmax(min(100%, X), 1fr))` — сітка без медіазапитів, яка не вилазить.
- `flex-wrap: wrap` + `flex: 1 1 X` — рядок, що переноситься.
- `aspect-ratio` + `object-fit: cover` — однакові рамки для різних фото.
- Container query: `container-type: inline-size` на обгортці + `@container (min-width: …)`.
