# Адаптивна типографіка

На телефоні заголовок 48 px займає пів екрана, а на моніторі 24 px губиться. Хочеться, щоб текст **плавно** підлаштовувався під ширину і при цьому не ламав головного: людина може збільшити текст, і сторінка це витримує.

## Два різні «збільшити»

| Що робить людина | Що змінюється |
|---|---|
| **Масштаб** браузера (Ctrl + «+», жест на телефоні) | збільшується все: px, rem, картинки. А ширина вікна в CSS px **зменшується**: 1280 px при 200 % — це 640 CSS px |
| **Розмір шрифту** в налаштуваннях браузера (наприклад, 20 px замість 16) | змінюються лише `rem` і `em` (і медіазапити в em), а `px` лишаються тими самими |

WCAG 1.4.4 **Resize Text**: текст має збільшуватися до 200 % без втрати вмісту. Тому:

- розміри шрифтів пиши в `rem`: вони йдуть за налаштуванням людини;
- **не пиши** `html { font-size: 16px; }`: це перекриває налаштування. Якщо треба змінити базу, роби це у відсотках (`100%` — як у людини).

## Чому не просто vw

```css
.headline { font-size: 5vw; }   /* 16 px на 320, 96 px на 1920 */
```

На телефоні замало, на моніторі забагато, а головне — **не збільшується**. При масштабі 200 % ширина вікна в CSS px удвічі менша, тож `5vw` удвічі менше, і на екрані заголовок лишається того самого розміру. Налаштування шрифту `vw` теж ігнорує.

## clamp(): плавно, але в межах

Сайт кулінарних рецептів:

```css
.recipe-title {
  font-size: clamp(1.5rem, 1rem + 2vw, 2.75rem);
}
```

`clamp(мінімум, бажане, максимум)`:

- **мінімум** `1.5rem` (24 px) — на найвужчому екрані не дрібніше;
- **бажане** `1rem + 2vw` — росте з шириною вікна, а частина в `rem` росте ще й з налаштуванням шрифту та масштабом;
- **максимум** `2.75rem` (44 px) — на моніторі не гігантський.

| Ширина вікна | 1rem + 2vw | Результат |
|---|---|---|
| 320 px | 16 + 6,4 = 22,4 | 24 px (мінімум) |
| 768 px | 16 + 15,36 = 31,36 | 31,36 px |
| 1600 px | 16 + 32 = 48 | 44 px (максимум) |

Межі теж пиши в `rem`: тоді й вони ростуть разом з налаштуванням шрифту.

> [!TIP]
> Як підібрати бажане значення: вирішити, яким має бути шрифт на двох ширинах. Наприклад, 24 px на 320 px і 44 px на 1280 px: ріст 20 px на 960 px ширини — це 20 / 960 = 2,083vw. На 320 px ця частина дає 6,67 px, тож решта — 24 − 6,67 = 17,33 px = 1,083rem. Разом: `clamp(1.5rem, 1.083rem + 2.083vw, 2.75rem)`. Те саме рахують онлайн-калькулятори fluid typography.

## Те саме для відступів

`clamp()` працює з будь-якою довжиною:

```css
.recipe-hero { padding-block: clamp(1.5rem, 5vw, 4rem); }
```

## Довжина рядка й інтерліньяж

- Зручний рядок — 45–75 символів: `max-width: 65ch` (модуль CSS, урок 4).
- `line-height` без одиниць: 1.5 для тексту, 1.1–1.25 для великих заголовків. Він масштабується разом зі шрифтом.
- `text-wrap: balance` вирівнює рядки заголовка, щоб останнє слово не висіло саме (в усіх браузерах з 2024 року).

## Text spacing: не фіксуй висоту тексту

WCAG 1.4.12 **Text Spacing**: людина може підставити свої інтервали — інтерліньяж 1.5, відступ після абзацу у 2 розміри шрифту, між літерами 0.12em, між словами 0.16em. Так, наприклад, легше читати людям з дислексією. Сторінка має це витримати без обрізаного й накладеного тексту.

Найчастіша причина поломки — фіксована висота блоку з текстом:

```css
.recipe-hero { height: 240px; }       /* текст стане довшим — вилізе за блок */
.recipe-hero { min-height: 240px; }   /* блок росте разом з текстом */
```

> [!QA]
> Перевірка за дві хвилини. У налаштуваннях Chrome (Appearance → Font size) постав Very large: текст має збільшитися, а розкладка — не розвалитися. Потім Ctrl + «+» до 200 %: текст більшає, нічого не обрізано, горизонтальної прокрутки немає (крім таблиць).

## Підсумок

- Масштаб збільшує все; налаштування шрифту — лише `rem` / `em`. Підтримуй обидва.
- Не задавай `html { font-size }` у px.
- Чистий `vw` для шрифту не збільшується — потрібна частина в `rem`.
- `clamp(мінімум у rem, rem + vw, максимум у rem)` — плавний шрифт у межах; так само для відступів.
- Рядок до ~65ch, `line-height` без одиниць, `text-wrap: balance` для заголовків.
- Висоту блоків з текстом не фіксуй: `min-height` замість `height`.
