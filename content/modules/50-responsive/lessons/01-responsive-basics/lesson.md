# Основи адаптивного дизайну

Одну сторінку відкривають на телефоні завширшки 360 px, на планшеті, на ноутбуці й на моніторі 2560 px. **Адаптивний дизайн** (responsive design) — це коли сторінка **одна**, а розкладка підлаштовується під будь-яку ширину: текст читається без збільшення, кнопки зручно натискати, нічого не вилазить за край екрана.

Більше половини відвідувань сайтів — з телефонів. Сторінка, яку доводиться гортати вбік або збільшувати пальцями, для цих людей просто зламана.

## Крок 1: meta viewport

```html
<meta name="viewport" content="width=device-width, initial-scale=1">
```

Без цього рядка мобільний браузер вдає, що екран завширшки ~980 px: малює сторінку як для комп'ютера і зменшує її до розміру телефона. Текст дрібний, а медіазапити (урок 2) бачать «980 px» і не спрацьовують. З рядком ширина сторінки дорівнює ширині екрана в **CSS-пікселях**: на iPhone це 390 px, хоча фізичних пікселів утричі більше.

> [!WARNING]
> Не додавай у viewport `user-scalable=no` чи `maximum-scale=1`. Людям зі слабким зором треба збільшувати сторінку пальцями, а ці значення це забороняють (WCAG 1.4.4 Resize Text).

## Крок 2: гнучкі ширини замість фіксованих

Каталог бібліотеки з фіксованою шириною:

```css
.catalog { width: 1100px; margin: 0 auto; }   /* на телефоні — теж 1100 px: гортай вбік */
```

Гнучкий варіант:

```css
.catalog {
  max-width: 1100px;   /* на великому екрані не ширше за 1100 px */
  margin: 0 auto;      /* по центру */
  padding: 0 16px;     /* поля, щоб текст не лип до країв телефона */
}
```

`max-width` замість `width`: на широкому екрані блок 1100 px, на вузькому — стільки, скільки є. З `box-sizing: border-box` (модуль CSS, урок 3) padding не додається до ширини.

## Крок 3: медіа не ширші за свій блок

```css
img, video {
  max-width: 100%;   /* не ширше за батька */
  height: auto;      /* висота — за пропорціями */
}
```

Атрибути `width` і `height` в HTML залишаються: з них браузер знає пропорції ще до завантаження і резервує місце, тож сторінка не «стрибає». `height: auto` зберігає ці пропорції, коли фото стискається. Без нього висота лишиться з атрибута, і фото сплющиться.

## Звідки береться горизонтальна прокрутка

Майже завжди винен **один** елемент, ширший за екран:

- фіксована ширина блоку (`width: 960px`) або поля (`width: 400px`);
- фото чи відео без `max-width: 100%`;
- довге слово без пробілів: URL, email, номер рахунку;
- `width: 100vw` разом з padding — блок ширший за екран на розмір полів;
- рядок flex-елементів, які не переносяться;
- широка таблиця з даними.

Довгі слова переносить `overflow-wrap: anywhere` — браузер розриває слово в будь-якому місці, коли воно не влазить.

Таблиця з даними — виняток, якому дозволено прокручуватися: п'ять колонок у 320 px не стиснеш. Але прокручується **лише вона**, а не вся сторінка:

```html
<div class="table-scroll">
  <table>…</table>
</div>
```

```css
.table-scroll { overflow-x: auto; }
```

> [!TIP]
> Сучасні браузери дають прокручуваному блоку фокус з клавіатури, але надійніше додати обгортці `tabindex="0"` і назву (`aria-labelledby` з id підпису таблиці): тоді прокрутити таблицю стрілками зможе будь-хто.

> [!WARNING]
> `body { overflow-x: hidden; }` — не виправлення, а маскування. Прокрутка зникає, а те, що вилазить, просто обрізається: людина не побачить кінець рядка чи кнопку. Знайди елемент, що вилазить, і виправ саме його.

## Reflow: 320 px і збільшення 400 %

Критерій WCAG 1.4.10 **Reflow**: вміст має читатися на ширині **320 CSS px** без горизонтальної прокрутки (крім таблиць, карт і схем, яким вона справді потрібна). Це не лише про маленькі телефони. Людина, що збільшила сторінку до 400 % на моніторі 1280 px, бачить ті самі 320 CSS px. Адаптивна сторінка автоматично допомагає людям зі слабким зором.

## Mobile first

Найпростіше починати з **вузького** екрана: одна колонка, усе одне під одним. Така сторінка майже не потребує CSS для розкладки — потік документа і так кладе блоки один під одним. Коли місця більше, додаєш колонки (урок 2). Це підхід **mobile first**.

> [!QA]
> Перевіряй сторінку на 320 px і плавно тягни вікно до найширшого: верстка не має ламатися на жодній проміжній ширині. Швидка перевірка в консолі: `document.documentElement.scrollWidth > document.documentElement.clientWidth` — `true` означає, що щось вилазить. Як знайти, **що саме**, — в уроці 7.

## Підсумок

- `<meta name="viewport" content="width=device-width, initial-scale=1">` — і без заборони масштабу.
- `max-width` + `margin: 0 auto` + поля замість фіксованої `width`.
- `img { max-width: 100%; height: auto; }` + атрибути `width` / `height` в HTML.
- Таблиця прокручується в обгортці з `overflow-x: auto`; довгі слова — `overflow-wrap: anywhere`.
- Не ховай прокрутку через `overflow-x: hidden` — шукай причину.
- 320 CSS px без горизонтальної прокрутки = WCAG Reflow.
