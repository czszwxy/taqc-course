# Медіазапити

Гнучкі ширини з уроку 1 роблять сторінку **придатною** для будь-якого екрана. Але на ноутбуці одна колонка на всю ширину незручна: рядки по 200 символів, багато порожнечі. **Медіазапит** (media query) вмикає правила лише тоді, коли пристрій відповідає умові: «якщо ширина від 640 px — дві колонки».

## Синтаксис

Сайт рецептів, картки страв:

```css
.recipes { display: grid; gap: 16px; }          /* базово: одна колонка */

@media (min-width: 40em) {                       /* від 640 px */
  .recipes { grid-template-columns: 1fr 1fr; }
}

@media (min-width: 64em) {                       /* від 1024 px */
  .recipes { grid-template-columns: repeat(3, 1fr); }
}
```

- `@media (умова) { правила }` — правила всередині діють, лише поки умова виконується.
- `min-width: 40em` — «ширина **від** 40em», `max-width: 40em` — «**до** 40em включно».
- Медіазапит не додає специфічності. Правило в ньому перемагає, бо стоїть **нижче** у файлі, тому медіазапити пишуть після базових правил.

## Mobile first: min-width

| Mobile first | Desktop first |
|---|---|
| базові правила — для телефона | базові правила — для комп'ютера |
| `@media (min-width: …)` **додає** колонки | `@media (max-width: …)` **скасовує** колонки |
| від простого до складного | спершу будуєш, потім розбираєш |

Mobile first простіше: телефонна розкладка — це зазвичай «усе одне під одним», тобто для неї майже нічого не треба писати, а медіазапити лише додають. У desktop first на вузьких екранах доводиться скасовувати ширини, колонки, `flex`, і щось обов'язково забудеш.

## Range syntax

Новіший запис (в усіх браузерах з 2023 року) читається як математика:

```css
@media (width >= 40em) { … }           /* те саме, що min-width: 40em */
@media (width < 40em) { … }            /* до 40em, НЕ включно */
@media (40em <= width < 64em) { … }    /* від 640 до 1023 px */
```

Пастка старого запису: `max-width: 768px` **включає** 768. Якщо поруч є `min-width: 768px`, то на рівно 768 px діють обидва правила. `width < 768px` цю пастку прибирає.

## Де ставити breakpoints

Не за моделями телефонів: їх сотні, і щороку з'являються нові. Став breakpoint **там, де ламається вміст**. Розтягуй вікно від 320 px і зупинись, коли рядки стали задовгими або з'явилося місце для другої колонки. Зазвичай виходить 2–3 точки.

Чому `em`: у медіазапитах `1em` — це розмір шрифту **за замовчуванням у браузері** (зазвичай 16 px). Якщо людина збільшила шрифт у налаштуваннях до 20 px, `40em` стане 800 px. Розкладка перейде на одну колонку раніше, і великий текст не стиснеться у вузькі колонки. З `px` такого не станеться.

## Не лише ширина

| Медіазапит | Коли діє | Для чого |
|---|---|---|
| `(orientation: landscape)` | ширина більша за висоту | відео на весь екран |
| `(hover: hover)` | основний пристрій уміє наводити (мишка) | ефекти наведення (урок 6) |
| `(pointer: coarse)` | основний пристрій — палець | більші кнопки |
| `(prefers-color-scheme: dark)` | у системі темна тема | темні кольори |
| `(prefers-reduced-motion: reduce)` | увімкнено «Зменшити рух» | без анімацій (модуль CSS) |
| `print` | сторінку друкують | сховати меню й кнопки |

Умови об'єднують: `and` — обидві, кома — хоча б одна, `not` — навпаки.

```css
@media screen and (min-width: 40em) and (orientation: landscape) { … }
@media (max-width: 30em), (orientation: portrait) { … }
```

## Темна тема через змінні

Якщо кольори вже у змінних CSS (модуль CSS, урок 4), темна тема — це нові значення тих самих змінних. Новинний сайт:

```css
:root {
  color-scheme: light dark;    /* браузер теж перефарбує поля, скролбари */
  --news-bg: #ffffff;
  --news-ink: #111827;
}

@media (prefers-color-scheme: dark) {
  :root {
    --news-bg: #0f172a;
    --news-ink: #e5e7eb;
  }
}

body { background-color: var(--news-bg); color: var(--news-ink); }
```

Компоненти не змінюються взагалі — лише токени. Контраст 4.5 : 1 потрібен і в темній темі: світло-сірий текст, що добре читався на білому, може зникнути на темно-синьому.

## Стилі для друку

Квиток на концерт хочуть роздрукувати:

```css
@media print {
  .site-menu, .share-buttons { display: none; }
  .ticket a[href^="http"]::after { content: " (" attr(href) ")"; }
}
```

На папері не натиснеш меню чи кнопку, а посилання без адреси марне. І пам'ятай про темну тему: якщо в людини вона увімкнена, на папір піде світлий текст. Тому в `@media print` повертають чорний текст на білому — **нижче** за темну тему у файлі, бо при однаковій специфічності перемагає останнє правило.

> [!QA]
> Медіазапити — це межі класів еквівалентності, тільки для ширини екрана. Для breakpoint 40em перевіряй 639, 640 і 641 px. Темну тему й друк можна перевірити, не змінюючи налаштувань системи: DevTools → **Rendering** → Emulate CSS media feature `prefers-color-scheme` і Emulate CSS media type `print`.

## Підсумок

- `@media (умова) { … }` — правила для певних пристроїв; пиши їх після базових правил.
- Mobile first: базові правила для телефона, `min-width` (або `width >=`) додає колонки.
- Breakpoints — там, де ламається вміст, а не за моделями телефонів; `em` поважає налаштування шрифту.
- `width < 768px` замість `max-width: 768px` прибирає накладання на межі.
- `prefers-color-scheme` + змінні CSS + `color-scheme` = темна тема; `print` — стилі для друку.
