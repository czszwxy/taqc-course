# Live coding на Python

На live coding для QA Automation рідко дають складні алгоритми. Частіше — задачі «з роботи»: порівняти очікуване з фактичним, розібрати лог, знайти дублікати, пройти вкладений JSON, написати допоміжний декоратор. Оцінюють не лише результат, а й **як ти думаєш**: чи уточнюєш умову, чи згадуєш крайні випадки, чи перевіряєш свій код.

## Алгоритм на 20–30 хвилин

| Крок | Що кажеш і робиш |
|---|---|
| 1. Уточнити | «Регістр важливий? Що повернути для порожнього списку? Можуть бути дублікати?» |
| 2. Приклади | 2–3 приклади входу й виходу, зокрема крайній (порожній, один елемент) |
| 3. Простий розв'язок | спершу робочий і зрозумілий, навіть якщо не найшвидший |
| 4. Перевірка | проганяєш приклади вголос або запускаєш; крайні випадки окремо |
| 5. Покращення | «Можна швидше через `set` — пошук за O(1)» |

> [!TIP]
> Мовчання — найгірше на live coding. Навіть коли не знаєш відповіді, проговорюй: «Спершу розіб'ю рядок на частини… тут треба перевірити, що частин рівно чотири…». Інтерв'юер часто підкаже, якщо бачить хід думок.

## Інструменти, що економлять час

| Задача | Інструмент |
|---|---|
| Порахувати повтори | `Counter(items)`, `.most_common(3)` |
| Згрупувати | `defaultdict(list)` або `dict.setdefault(key, [])` |
| Унікальні / перетин / різниця | `set`, `a & b`, `a - b` |
| Сортування за кількома ключами | `sorted(items, key=lambda x: (-x[1], x[0]))` |
| Індекс і значення | `enumerate(items)` |
| «Хоч один» / «усі» | `any(...)`, `all(...)` (пам'ятай `all([])` — `True`) |
| Тип значення | `isinstance(value, dict)` |

## Складність простими словами

- `x in some_list` перебирає весь список — **O(n)**; `x in some_set` — **O(1)** у середньому.
- Цикл у циклі по тих самих даних — **O(n²)**: на 10 000 елементів — 100 мільйонів кроків.
- Типове покращення на співбесіді: «замість вкладеного циклу — множина або словник».

## Розбір: дублікати email без урахування регістру

```python
from collections import Counter


def duplicate_emails(emails):
    counts = Counter(email.strip().lower() for email in emails)
    return sorted(email for email, count in counts.items() if count > 1)
```

| Вхід | `counts` | Результат |
|---|---|---|
| `["QA@x.test", "qa@x.test ", "dev@x.test"]` | `{"qa@x.test": 2, "dev@x.test": 1}` | `["qa@x.test"]` |
| `[]` | `{}` | `[]` |

Уточнення, які варто проговорити: «пробіли довкола — шум?», «повертати в нижньому регістрі?», «порядок важливий?».

## Рекурсія для вкладених даних

JSON з API — це словники й списки будь-якої глибини. Їх зручно обходити рекурсією: функція викликає себе для кожного вкладеного значення.

```python
def count_keys(data):
    if isinstance(data, dict):
        return len(data) + sum(count_keys(value) for value in data.values())
    if isinstance(data, list):
        return sum(count_keys(item) for item in data)
    return 0


count_keys({"id": 7, "user": {"email": "qa@x.test"}, "tags": [{"name": "new"}]})   # 5
```

Три гілки: словник, список, «лист» (число, рядок, `None`). Базовий випадок — лист: далі заглиблюватися нікуди.

## Декоратор з параметрами

Коли декоратору потрібні налаштування (`@with_prefix("[API]")`), з'являється ще один рівень: функція приймає параметри і **повертає декоратор**.

```python
import functools


def with_prefix(prefix):
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            return f"{prefix} {func(*args, **kwargs)}"
        return wrapper
    return decorator


@with_prefix("[API]")
def describe(status):
    return f"status {status}"


describe(404)   # "[API] status 404"
```

| Рівень | Отримує | Повертає |
|---|---|---|
| `with_prefix(prefix)` | параметри декоратора | `decorator` |
| `decorator(func)` | функцію | `wrapper` |
| `wrapper(*args, **kwargs)` | аргументи виклику | результат |

## Типові помилки

- Почати писати код, не уточнивши, що повернути для порожнього входу.
- Не запустити (або не проговорити) жодного прикладу перед «готово».
- `if value:` там, де `0` чи `""` — нормальні значення; правильно — `if value is not None:`.
- Рекурсія без базового випадку або без гілки для списків.
- Декоратор без `return` результату чи без `functools.wraps`.

## Підсумок

- Уточни → приклади → простий розв'язок → перевір → покращ; думай уголос.
- `Counter`, `defaultdict`, `set`, `sorted(key=...)`, `enumerate`, `any/all`, `isinstance` — твої «швидкі клавіші».
- Складність: `in` по списку O(n), по множині O(1); вкладений цикл — O(n²).
- Вкладений JSON — рекурсія з гілками для словника, списку й листа.
- Декоратор з параметрами — три рівні: параметри → функція → виклик.
