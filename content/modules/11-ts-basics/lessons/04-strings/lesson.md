# Рядки та шаблонні рядки

Тексти повідомлень про помилки, заголовки сторінок, URL, email, назви тестів — усе це **рядки** (`string`). В автотестах ти постійно будуєш рядки (тестові дані, URL) і перевіряєш їх (текст на сторінці, поле JSON).

## Три види лапок

```ts
const a = 'single quotes';
const b = "double quotes";
const c = `backticks — template literal`;
```

Одинарні й подвійні лапки працюють однаково. Обирай один стиль і дотримуйся його (у цьому курсі — одинарні). **Зворотні** лапки (backticks, клавіша під Esc) дають **шаблонний рядок**.

## Шаблонні рядки (template literals)

Усередину шаблонного рядка можна вставляти значення через `${...}`:

```ts
const user = 'Olena';
const count = 3;

// склеювання через + : легко загубити пробіл
const msg1 = 'User ' + user + ' has ' + count + ' failed tests';

// шаблонний рядок: читається як звичайний текст
const msg2 = `User ${user} has ${count} failed tests`;
```

У `${}` можна писати будь-який вираз: `${count + 1}`, `${price * 2}`, `${name.toUpperCase()}`.

Шаблонні рядки бувають **багаторядковими**:

```ts
const report = `Suite: Login
Passed: 12
Failed: 1`;
```

## Довжина та символи

```ts
const code = 'QA-2024';
code.length;   // 7
code[0];       // 'Q' — індексація з нуля!
code[code.length - 1]; // '4' — останній символ
code.at(-1);   // '4' — те саме, але коротше
```

> [!IMPORTANT]
> Індекси починаються з **0**: перший символ має індекс `0`, останній — `length - 1`. Це звідки береться класична помилка «off by one» (зсув на одиницю).

## Рядки незмінні

Методи рядків **не змінюють** оригінал, вони повертають **новий** рядок:

```ts
const email = '  QA@Example.com ';
email.trim();   // 'QA@Example.com'
console.log(email); // '  QA@Example.com ' — оригінал не змінився!

const clean = email.trim().toLowerCase(); // зберігаємо результат
```

## Найважливіші методи

| Метод | Що робить | Приклад → результат |
|---|---|---|
| `toUpperCase()` / `toLowerCase()` | регістр | `'Login'.toUpperCase()` → `'LOGIN'` |
| `trim()` | прибирає пробіли з країв | `'  hi '.trim()` → `'hi'` |
| `includes(s)` | чи містить підрядок | `'Error 404'.includes('404')` → `true` |
| `startsWith(s)` / `endsWith(s)` | чи починається / закінчується | `'/api/users'.startsWith('/api')` → `true` |
| `indexOf(s)` | позиція підрядка або `-1` | `'a-b-c'.indexOf('b')` → `2` |
| `slice(start, end)` | частина рядка (end не включно) | `'TC-0042'.slice(3)` → `'0042'` |
| `replace(a, b)` | замінити **перше** входження | `'a-b-c'.replace('-', '+')` → `'a+b-c'` |
| `replaceAll(a, b)` | замінити **всі** входження | `'a-b-c'.replaceAll('-', '+')` → `'a+b+c'` |
| `split(sep)` | розбити на масив | `'a,b,c'.split(',')` → `['a', 'b', 'c']` |
| `repeat(n)` | повторити n разів | `'*'.repeat(3)` → `'***'` |
| `padStart(len, ch)` | доповнити зліва до довжини | `'7'.padStart(3, '0')` → `'007'` |

`slice` з від'ємним числом рахує з кінця: `'password123'.slice(-3)` → `'123'`.

Методи можна з'єднувати в **ланцюжок**: кожен наступний працює з результатом попереднього.

```ts
const title = '  bug: Login Fails  '.trim().toLowerCase().replace('bug: ', '');
// 'login fails'
```

## Порівняння рядків

`===` порівнює рядки **посимвольно і з урахуванням регістру**:

```ts
'Admin' === 'admin';                              // false
'Admin'.toLowerCase() === 'admin'.toLowerCase();  // true — порівняння без регістру
```

> [!QA]
> Пробіли на початку й у кінці та різний регістр — джерело багів у логінах та пошуку. Типові перевірки: чи пускає логін з email `' User@Mail.com '`? Чи знаходить пошук «iphone», якщо товар називається «iPhone»? Вимоги мають це визначати, а тести — перевіряти.

## Спецсимволи

| Запис | Значення |
|---|---|
| `\n` | перенос рядка |
| `\t` | табуляція |
| `\'` | одинарна лапка всередині `'...'` |
| `\\` | сам символ `\` |

```ts
const msg = 'It\'s a bug';      // або "It's a bug"
const lines = 'line 1\nline 2'; // два рядки
```

## Перетворення в рядок і з рядка

```ts
String(42);        // '42'
(42).toString();   // '42'
Number('42');      // 42
Number('42px');    // NaN — не число
```

> [!WARNING]
> Значення з полів форми та з URL завжди приходять **рядками**. `'10' + 5` дасть `'105'`, а не `15`. Спершу перетвори значення через `Number(...)`.

## Підсумок

- Шаблонні рядки `` `Hello ${name}` `` — найзручніший спосіб будувати текст.
- Індекси з 0, останній символ — `length - 1` або `at(-1)`.
- Методи не змінюють оригінал, вони повертають новий рядок.
- `trim`, `toLowerCase`, `includes`, `slice`, `replaceAll`, `split`, `padStart` — твій базовий набір.
- Для порівняння без урахування регістру зведи обидва рядки до одного регістру.
