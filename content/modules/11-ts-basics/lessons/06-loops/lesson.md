# Цикли

Цикл повторює код кілька разів. В автотестах це, наприклад: пройтися по всіх рядках таблиці, перевірити кожен товар у кошику, повторити запит, поки статус не стане `done`.

## for: коли відомо, скільки разів

```ts
for (let i = 1; i <= 3; i++) {
  console.log(`Attempt ${i}`);
}
// Attempt 1
// Attempt 2
// Attempt 3
```

Заголовок `for` має три частини, розділені `;`:

| Частина | Приклад | Коли виконується |
|---|---|---|
| ініціалізація | `let i = 1` | один раз, перед стартом |
| умова | `i <= 3` | перед **кожною** ітерацією: якщо `false`, цикл завершується |
| крок | `i++` | після кожної ітерації |

## while: поки умова істинна

```ts
let attempts = 0;
while (attempts < 3) {
  console.log('Retrying…');
  attempts++;
}
```

`while` зручний, коли кількість повторів заздалегідь невідома: «чекати, поки елемент з'явиться».

`do...while` спершу виконує тіло, а потім перевіряє умову, тож тіло виконається хоча б один раз:

```ts
let n = 0;
do {
  n++;
} while (n < 0); // n === 1: тіло виконалось один раз
```

> [!WARNING]
> Якщо умова ніколи не стане `false`, цикл буде **нескінченним**, і програма зависне. Наприклад, у `while` забули `attempts++`. У цьому застосунку виконання зупиняється через 5 секунд з повідомленням про ймовірний нескінченний цикл.

## for...of: перебір елементів

`for...of` перебирає елементи по одному. Для рядка елементами є символи:

```ts
const results = 'PPFPF'; // P = passed, F = failed
for (const r of results) {
  console.log(r); // P, P, F, P, F
}
```

Так само працює з масивами (наступні уроки): `for (const user of users) { ... }`.

## Типові шаблони

### Лічильник

```ts
let failed = 0;
for (const r of 'PPFPF') {
  if (r === 'F') {
    failed++;
  }
}
console.log(failed); // 2
```

### Накопичувач (сума)

```ts
let sum = 0;
for (let i = 1; i <= 5; i++) {
  sum += i;
}
console.log(sum); // 15
```

### Побудова рядка

```ts
let line = '';
for (let i = 1; i <= 3; i++) {
  line += `#${i} `;
}
console.log(line); // '#1 #2 #3 '
```

## break і continue

- `break` — **вийти** з циклу одразу.
- `continue` — **пропустити** решту поточної ітерації і перейти до наступної.

```ts
// знайти першу помилку і зупинитися
const results = 'PPPFPP';
for (let i = 0; i < results.length; i++) {
  if (results[i] === 'F') {
    console.log(`First failure at position ${i + 1}`);
    break;
  }
}

// пропустити skipped-тести
for (const r of 'PSPSF') {
  if (r === 'S') continue;
  console.log(r); // P, P, F
}
```

Усередині функції замість `break` часто зручніше одразу зробити `return`.

## Перебір рядка за індексами

```ts
const text = 'QA';
for (let i = 0; i < text.length; i++) {
  console.log(i, text[i]); // 0 'Q', 1 'A'
}
```

> [!IMPORTANT]
> Індекси від `0` до `length - 1`. Тому умова саме `i < text.length`. Варіанти `i <= text.length` або старт з `i = 1` — класичні помилки **off-by-one** (на одиницю).

> [!QA]
> Off-by-one у коді — це **граничний баг** у продукті: остання сторінка пагінації не показується, перший елемент списку пропущено, десятий товар не потрапляє в кошик. Перевіряй перший, останній і «один після останнього» елементи.

## Вкладені цикли

Цикл усередині циклу перебирає всі комбінації:

```ts
for (const browser of ['chromium', 'firefox']) {
  for (const size of ['mobile', 'desktop']) {
    console.log(`${browser} × ${size}`);
  }
}
// 4 комбінації
```

Саме так Playwright запускає один тест у кількох браузерах і на кількох розмірах екрана.

## Підсумок

- `for` — коли відомо, скільки разів; `while` — поки умова істинна; `for...of` — перебір елементів.
- Шаблони: лічильник (`count++`), накопичувач (`sum += x`), побудова рядка (`line += ...`).
- `break` виходить з циклу, `continue` переходить до наступної ітерації.
- Стережися нескінченних циклів і помилок «на одиницю».
