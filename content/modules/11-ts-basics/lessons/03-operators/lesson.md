# Оператори, порівняння, truthy і falsy

Будь-яка перевірка в тесті зводиться до **порівняння**: «сума дорівнює 150?», «статус-код більший за 399?», «кнопка видима **і** активна?». Інструменти для цього — оператори.

## Арифметичні оператори

| Оператор | Значення | Приклад | Результат |
|---|---|---|---|
| `+` | додавання | `7 + 3` | `10` |
| `-` | віднімання | `7 - 3` | `4` |
| `*` | множення | `7 * 3` | `21` |
| `/` | ділення | `7 / 2` | `3.5` |
| `%` | остача від ділення | `7 % 3` | `1` |
| `**` | степінь | `2 ** 3` | `8` |

Порядок дій як у математиці: спершу `**`, потім `* / %`, потім `+ -`. Якщо сумніваєшся, став дужки: `(price + tax) * quantity`.

> [!TIP]
> `%` (остача) корисніший, ніж здається: `n % 2 === 0` означає, що число парне. `index % 3 === 0` означає «кожен третій елемент».

### Скорочене присвоєння

```ts
let count = 10;
count += 5;  // count = count + 5  → 15
count -= 3;  // count = count - 3  → 12
count *= 2;  // → 24
count++;     // збільшити на 1     → 25
count--;     // зменшити на 1      → 24
```

## Порівняння

Порівняння завжди повертає `boolean`: `true` або `false`.

| Оператор | Значення |
|---|---|
| `===` | строго дорівнює (значення **і** тип) |
| `!==` | строго не дорівнює |
| `>` `<` | більше, менше |
| `>=` `<=` | більше або дорівнює, менше або дорівнює |

```ts
200 === 200;   // true
'200' === 200; // false: рядок і число
404 >= 400;    // true
```

> [!IMPORTANT]
> Використовуй **тільки** `===` і `!==`. Старі `==` і `!=` перед порівнянням перетворюють типи, і `'0' == 0` дає `true`, а `'' == 0` теж дає `true`. Такі «магічні» порівняння ховають баги.

> [!QA]
> Різниця між `>` і `>=` — одне з найчастіших джерел **граничних багів** (boundary bugs). Вимога «від 18 років» означає `age >= 18`. Якщо розробник написав `age > 18`, 18-річного користувача не пустить. Тому тестувальники завжди перевіряють саму межу.

## Логічні оператори

| Оператор | Назва | `true` коли… |
|---|---|---|
| `&&` | І (AND) | **обидві** частини true |
| `\|\|` | АБО (OR) | **хоча б одна** частина true |
| `!` | НЕ (NOT) | перевертає значення |

```ts
const isLoggedIn = true;
const isAdmin = false;

isLoggedIn && isAdmin;   // false
isLoggedIn || isAdmin;   // true
!isAdmin;                // true
```

Таблиця істинності для `a && b` і `a || b`:

| a | b | a && b | a \|\| b |
|---|---|---|---|
| true | true | true | true |
| true | false | false | true |
| false | true | false | true |
| false | false | false | false |

> [!QA]
> Це майже готова **таблиця рішень** (decision table), техніка тест-дизайну з модуля 3. Умова з 3 логічними змінними має 2³ = 8 комбінацій, і всі їх можна перевірити.

Можна комбінувати оператори і групувати дужками:

```ts
const canDeploy = (testsGreen && reviewApproved) || isHotfix;
```

## Truthy і falsy

У місцях, де очікується `boolean` (наприклад, в `if`), JavaScript перетворює будь-яке значення на `true` або `false`.

**Falsy** (стають `false`) — цих значень лише кілька, їх варто запам'ятати:

```ts
false, 0, -0, '', null, undefined, NaN
```

Усе інше **truthy**: `'0'`, `'false'`, `' '` (пробіл), `[]`, `{}`, `-1`…

```ts
const name = '';
if (name) {
  console.log('Name entered');   // не виконається: '' — falsy
}
```

> [!WARNING]
> `0` — falsy. Якщо кількість товарів може бути `0`, перевірка `if (quantity)` помилково вважатиме нуль «відсутнім значенням». Для таких випадків перевіряй явно: `quantity !== undefined`.

### Оператор `??`

`a ?? b` повертає `b`, тільки якщо `a` дорівнює `null` або `undefined`. На відміну від `||`, він **не** спрацьовує на `0` чи `''`:

```ts
const timeout = 0;
timeout || 5000; // 5000 — бо 0 falsy (часто це баг!)
timeout ?? 5000; // 0    — бо 0 не null і не undefined
```

## Корисне з Math

```ts
Math.round(4.5);  // 5  — до найближчого цілого
Math.floor(4.9);  // 4  — вниз
Math.ceil(4.1);   // 5  — вгору
Math.max(3, 9, 2); // 9
Math.min(3, 9, 2); // 2
Math.abs(-7);     // 7
```

Відсоток з округленням: `Math.round((passed / total) * 100)`.

## Підводні камені з числами

```ts
0.1 + 0.2;          // 0.30000000000000004 (!)
0.1 + 0.2 === 0.3;  // false
10 / 0;             // Infinity
'abc' * 2;          // NaN (Not a Number); TypeScript такий рядок не пропустить
```

Дробові числа зберігаються в двійковій системі неточно. У тестах **грошові суми** порівнюють після округлення або з допуском: `Math.round(total * 100) / 100`.

> [!QA]
> Баги округлення в кошиках і рахунках трапляються регулярно: «сума товарів 0.30, а в підсумку 0.31». Тестові дані з копійками (`19.99`, `0.1`) мають бути в кожному наборі перевірок для грошей.

## Підсумок

- Арифметика: `+ - * / % **`; `%` — остача.
- Порівнюй тільки через `===` та `!==`.
- `&&` — обидва, `||` — хоча б один, `!` — заперечення.
- Falsy: `false, 0, '', null, undefined, NaN`; усе інше truthy.
- `??` дає значення за замовчуванням лише для `null`/`undefined`.
- Дробові числа неточні: округлюй перед порівнянням.
