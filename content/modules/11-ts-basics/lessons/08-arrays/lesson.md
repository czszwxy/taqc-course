# Масиви

Масив — це впорядкований список значень. Тестові дані дуже часто бувають списками: email-и для перевірки валідації, товари в кошику, рядки таблиці, тривалості тестів зі звіту.

## Створення і типи

```ts
const browsers: string[] = ['chromium', 'firefox', 'webkit'];
const durations: number[] = [1200, 850, 3100];
const flags: boolean[] = [true, false];

const empty: string[] = [];          // порожній масив: тип треба вказати
const same: Array<string> = ['a'];   // інший запис того самого типу
```

TypeScript не дасть покласти в `string[]` число: `browsers.push(42)` дасть помилку.

## Індекси й довжина

```ts
const steps = ['open', 'fill', 'submit'];

steps[0];                 // 'open' — індекси з 0
steps[2];                 // 'submit'
steps.length;             // 3
steps[steps.length - 1];  // 'submit' — останній
steps.at(-1);             // 'submit' — те саме
steps[10];                // undefined — такого елемента немає
```

> [!WARNING]
> Звернення до неіснуючого індексу не дає помилки, а повертає `undefined`. Потім `undefined.toUpperCase()` «вибухне» з помилкою `TypeError: Cannot read properties of undefined`. Перевіряй довжину масиву.

## Перебір

```ts
for (const step of steps) {
  console.log(step);
}

for (let i = 0; i < steps.length; i++) {
  console.log(`${i + 1}. ${steps[i]}`); // коли потрібен номер
}
```

## Додавання і видалення

| Метод | Що робить | Змінює масив? |
|---|---|---|
| `push(x)` | додає в кінець | так |
| `pop()` | видаляє останній і повертає його | так |
| `unshift(x)` | додає на початок | так |
| `shift()` | видаляє перший і повертає його | так |
| `splice(i, n)` | видаляє `n` елементів з позиції `i` | так |

```ts
const queue = ['test-1', 'test-2'];
queue.push('test-3');   // ['test-1', 'test-2', 'test-3']
queue.shift();          // повертає 'test-1', queue = ['test-2', 'test-3']
```

`const` у масиві забороняє **перепризначити змінну**, але не забороняє змінювати вміст: `queue.push(...)` працює і для `const`.

## Пошук і перевірки

```ts
const tags = ['smoke', 'regression', 'api'];

tags.includes('api');     // true
tags.indexOf('regression'); // 1
tags.indexOf('ui');       // -1 — не знайдено
tags.length === 0;        // перевірка на порожній масив
```

## Методи, що повертають новий масив або рядок

| Метод | Приклад | Результат |
|---|---|---|
| `slice(start, end)` | `['a','b','c','d'].slice(1, 3)` | `['b', 'c']` |
| `concat(other)` | `['a'].concat(['b'])` | `['a', 'b']` |
| `join(sep)` | `['a','b','c'].join(', ')` | `'a, b, c'` |
| `[...arr]` (spread) | `[...tags]` | копія масиву |
| `[...a, ...b]` | `[...['a'], ...['b'], 'c']` | `['a', 'b', 'c']` |

А `split` робить зворотне до `join`: рядок → масив. `'a,b'.split(',')` дає `['a', 'b']`.

## Масиви передаються за посиланням

```ts
const original = ['login', 'logout'];
const copy = original;   // НЕ копія! Це те саме посилання
copy.push('signup');
console.log(original);   // ['login', 'logout', 'signup'] 😱

const realCopy = [...original]; // справжня (поверхнева) копія
realCopy.push('reset');
console.log(original);   // не змінився
```

Масиви (і об'єкти) зберігаються **за посиланням**: змінна містить «адресу» масиву, а не сам масив. Дві змінні можуть вказувати на один і той самий масив.

> [!QA]
> Це джерело підступних багів в автотестах. Якщо один тест змінює **спільний** масив тестових даних (`testUsers.push(...)`), наступний тест отримає вже інші дані й упаде «випадково». Тести мають бути **незалежними**. Функції, що працюють з даними, краще писати так, щоб вони повертали **новий** масив і не змінювали вхідний.

## Порівняння масивів

```ts
[1, 2] === [1, 2]; // false! Це два різні масиви в пам'яті
```

`===` для масивів порівнює посилання, а не вміст. Щоб порівняти вміст, перебери елементи (або використай `toEqual` у тестах — він порівнює глибоко).

## Що далі

`map`, `filter`, `find`, `reduce`, `sort` — найпотужніші методи масивів — розберемо в модулі «Types & Data». Поки розв'язуй задачі циклами: так краще видно, що відбувається.

## Підсумок

- `string[]` / `number[]` — типізовані масиви; порожньому масиву вказуй тип явно.
- Індекси з 0; звернення за межі дає `undefined`.
- `push/pop/shift/unshift/splice` змінюють масив; `slice/concat/join/spread` — ні.
- `includes`, `indexOf` — пошук; `length === 0` — перевірка на порожній масив.
- Масиви передаються за посиланням: копіюй через `[...arr]`, а вхідні дані не мутуй.
