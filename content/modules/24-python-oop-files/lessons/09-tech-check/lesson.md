# Tech check: Python

На співбесіді на Python QA Automation мову перевіряють обов'язково — і не лише «напиши функцію», а й «поясни словами»: «Чим список відрізняється від кортежу?», «Що не так з `def f(items=[])`?», «Що таке генератор і де він у pytest?». Цей tech check закриває блок Python. Блок вважається пройденим, коли ти його складеш.

## Як проходить сесія

1. 12 випадкових питань з банку — рівномірно з кожного модуля блоку, тема за темою.
2. На кожне — близько 2 хвилин. Відповідай **уголос**, ніби навпроти сидить інтерв'юер.
3. Відкриваєш еталонну відповідь і відмічаєш ключові пункти, які ти **справді сказав**.
4. Прохідний бал — 80%. Повторна спроба — новий набір питань.

## Як відповідати на питання про Python

- **Визначення + маленький приклад коду**, проговорений словами: «`b = a` не копіює список — обидві змінні вказують на той самий об'єкт, тому `b.append(1)` змінить і `a`».
- **Що зламається, якщо помилитися.** Інтерв'юер на позицію автоматизатора чекає зв'язку з тестами: спільний default робить тести залежними, `all([])` дає хибно зелений тест.
- **Приклади з курсу.** Білдер тестових даних з `**overrides`, `retry` з callback, репозиторій користувачів з міні-проєкту — це готові відповіді «а де ти це використовував?».
- **Не вигадуй назви.** Не пам'ятаєш точний метод — опиши поведінку.

> [!TIP]
> Найчастіші «питання-пастки» на Python-співбесідах для QA: змінюваний default, копія і посилання, `is` і `==`, `all([])`, різниця `sort` і `sorted`, `except: pass`. У цьому банку є кожне.

## Що перевіряє цей tech check

| Тема | Про що питають |
|---|---|
| Основи Python | `print` vs `return`, типи й перетворення, `/` `//` `%`, f-strings, truthy / falsy і пастка з `or`, цикли, traceback |
| Колекції | список vs кортеж, копія vs посилання, словники й `get`, множини, comprehensions, `all([])`, сортування, JSON |
| Функції, модулі, помилки | `*args` / `**kwargs`, змінюваний default, замикання, винятки й `raise … from`, генератори, type hints, імпорт |
| ООП, файли, проєкт | клас і `self`, атрибут класу, наслідування vs композиція, dataclasses, dunder-методи, файли й encoding, CSV / JSON, venv і requirements |

## Підсумок

- Python на співбесіді — це «поясни словами», а не лише «напиши код».
- Відповідь: визначення → маленький приклад → де це в тестах → що зламається.
- Знай класичні пастки: змінюваний default, копія і посилання, `all([])`, `except: pass`.
- Не склав — повтори модулі з «revisit» і розв'яжи схожі задачі.
