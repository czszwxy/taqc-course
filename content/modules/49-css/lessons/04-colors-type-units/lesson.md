# Кольори, шрифти й одиниці

Більшість сторінок — це текст на фоні. Якщо текст блідий, дрібний і стиснутий, жодна розкладка не врятує. У цьому уроці — кольори, читабельна типографіка, одиниці виміру і змінні CSS, які тримають дизайн узгодженим.

## Кольори

```css
.headline {
  color: #111827;                    /* hex: червоний, зелений, синій по 2 цифри */
  background-color: rgb(254 243 199); /* те саме в rgb() */
  border-color: hsl(217 91% 60%);    /* відтінок, насиченість, світлота */
}
.overlay {
  background-color: rgb(0 0 0 / 50%);  /* напівпрозорий чорний */
}
```

| Формат | Коли зручно |
|---|---|
| `#1d4ed8` | копіюєш з макета (Figma дає hex) |
| `rgb(29 78 216)` | з прозорістю: `rgb(29 78 216 / 40%)` |
| `hsl(224 76% 48%)` | зробити той самий колір світлішим чи темнішим — міняєш лише третє число |
| `transparent`, `currentColor` | прозорий; поточний колір тексту (зручно для рамок та іконок) |

**Контраст** — з уроку про доступність: звичайний текст — щонайменше **4,5 : 1** з фоном, великий — 3 : 1. Світло-сірий `#9ca3af` на білому дає лише ~2,5 : 1. DevTools показує контраст у піпетці кольору; швидко перевірити пару можна в WebAIM Contrast Checker.

## Шрифти

```css
body {
  font-family: system-ui, -apple-system, "Segoe UI", Roboto, sans-serif;
  font-size: 1rem;
  line-height: 1.6;
}
h1 {
  font-size: 2rem;
  line-height: 1.2;
  font-weight: 700;
}
```

- `font-family` — **стек**: якщо першого шрифту немає, браузер бере наступний; останнім — загальна родина (`sans-serif`, `serif`, `monospace`). `system-ui` — системний шрифт пристрою, нічого не треба завантажувати.
- Власні шрифти підключають через `@font-face` чи сервіс шрифтів, але кожен шрифт — це ще файли для завантаження: беріть 1–2 накреслення.
- `line-height` **без одиниці** (`1.6`) — множник від розміру шрифту, який правильно успадковується. З `24px` дрібний текст у нащадках «розлетиться», а великий — «злипнеться».
- Посилання в тексті залишай **підкресленими**: лише колір — погана ознака для тих, хто погано розрізняє кольори.

Читабельний абзац: 16–20 px, інтерліньяж 1,5–1,7, рядок 45–75 символів (`max-width: 65ch`).

## Одиниці

| Одиниця | Відносно чого | Для чого |
|---|---|---|
| `px` | піксель екрана (CSS-піксель) | рамки, тіні, дрібні деталі |
| `rem` | розмір шрифту `<html>` (зазвичай 16 px) | **розміри шрифтів**, відступи |
| `em` | розмір шрифту **самого елемента** | відступи кнопки, що ростуть разом з її текстом |
| `%` | розмір батька | ширини колонок |
| `ch` | ширина символу «0» шрифту | ширина тексту: `max-width: 65ch` |
| `vw` / `vh` | 1 % ширини / висоти вікна | великі заголовки банерів |
| `dvh` | 1 % **видимої** висоти (з урахуванням панелей браузера на телефоні) | перший екран на телефоні |

> [!IMPORTANT]
> Людина може збільшити базовий шрифт у налаштуваннях браузера (наприклад, з 16 до 24 px). `rem` поважає цей вибір, а `font-size: 14px` — ні: текст лишиться дрібним. Тому розміри шрифтів — у `rem`.

## Змінні CSS (custom properties)

Новинний сайт використовує той самий синій у двадцяти місцях. Замість копіювання — **змінна**:

```css
:root {
  --color-brand: #1d4ed8;
  --space: 16px;
  --radius: 8px;
}

.subscribe-button {
  background-color: var(--color-brand);
  padding: calc(var(--space) / 2) var(--space);
  border-radius: var(--radius);
}

.tag {
  border: 1px solid var(--color-brand);
  color: var(--color-accent, var(--color-brand));  /* друге значення — запасне */
}
```

- Ім'я починається з `--`, читається через `var(--ім'я)`.
- `:root` — це `<html>`: змінні там видно всій сторінці (вони **успадковуються**).
- Змінну можна перевизначити для частини сторінки: `.dark-section { --color-brand: #93c5fd; }` — і всі кнопки всередині стануть світлими.
- `calc()` рахує з різними одиницями: `calc(100% - 2rem)`, `calc(var(--space) * 2)`.

Такі змінні називають **design tokens** — «словник» дизайну. Ребрендинг сайту зводиться до зміни кількох рядків у `:root`.

## Підсумок

- Колір — у будь-якому форматі; контраст тексту ≥ 4,5 : 1.
- Шрифти — стеком з загальною родиною в кінці; розміри в `rem`; `line-height` без одиниць; посилання підкреслені.
- `rem` — шрифти, `em` — відступи, що ростуть з текстом, `%` — колонки, `ch` — ширина тексту, `px` — рамки.
- Повторювані значення — у змінних на `:root`; `var()` читає, `calc()` рахує.
