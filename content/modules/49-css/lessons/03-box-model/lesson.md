# Блокова модель

Для браузера кожен елемент — **прямокутник**. Розміри й відступи всіх прямокутників разом і дають розкладку сторінки. Якщо картка «чомусь» ширша, ніж написано, а між блоками «зайвий» відступ — відповідь майже завжди в блоковій моделі.

## Чотири шари

Картка у фотогалереї:

```css
.photo-card {
  width: 300px;
  padding: 16px;                 /* внутрішній відступ: від вмісту до рамки */
  border: 2px solid #d1d5db;     /* рамка */
  margin: 24px;                  /* зовнішній відступ: від рамки до сусідів */
}
```

```text
margin   ┌──────────────────────────────┐
border   │ ┌──────────────────────────┐ │
padding  │ │ ┌──────────────────────┐ │ │
content  │ │ │  фото й підпис       │ │ │
         │ │ └──────────────────────┘ │ │
         │ └──────────────────────────┘ │
         └──────────────────────────────┘
```

- `padding` — «повітря» всередині, має колір фону елемента.
- `border` — рамка.
- `margin` — прозорий відступ ззовні, відштовхує сусідів.

Скорочення працюють за годинниковою стрілкою від верху: `padding: 8px 16px` = верх і низ 8, ліво і право 16; `margin: 0 auto` = верх і низ 0, ліво і право `auto`.

## Яка ширина насправді: box-sizing

За замовчуванням (`box-sizing: content-box`) `width` — це ширина **лише вмісту**. Padding і border додаються зверху:

| | content-box (за замовчуванням) | border-box |
|---|---|---|
| `width: 300px; padding: 16px; border: 2px` | 300 + 16·2 + 2·2 = **336 px** | **300 px** (вміст стискається до 264) |

З `border-box` ширина означає те, що бачить людина: від рамки до рамки. Тому майже кожен проєкт починається з:

```css
*,
*::before,
*::after {
  box-sizing: border-box;
}
```

`margin` до ширини не входить у жодному режимі — він завжди зовні.

## Центрування й максимальна ширина

```css
.gallery {
  max-width: 960px;   /* не ширше 960, але може бути вужчим на телефоні */
  margin: 0 auto;     /* ліве й праве auto ділять вільне місце порівну */
}
```

`max-width` краще за `width`: на вузькому екрані блок просто стиснеться, а не вилізе за край.

## Схлопування вертикальних margin

```css
h2 { margin-bottom: 24px; }
p  { margin-top: 16px; }
```

Між `h2` і `p` буде **24 px**, а не 40: сусідні вертикальні margin звичайних блоків **схлопуються** — береться більший. Те саме буває між батьком і першою дитиною (margin дитини «вилазить» назовні батька). Горизонтальні margin і padding ніколи не схлопуються, а у Flexbox і Grid схлопування немає.

## display: block, inline, inline-block

| | `block` | `inline` | `inline-block` |
|---|---|---|---|
| Приклади за замовчуванням | `div`, `p`, `h1`, `ul`, `section` | `span`, `a`, `strong`, `img`, `label` | `button`, `input`, `select` |
| Новий рядок | так, займає всю ширину | ні, тече разом з текстом | ні |
| `width` / `height` | працюють | **ігноруються** | працюють |
| вертикальні `margin` / `padding` | працюють | padding малюється, але не відштовхує сусідні рядки | працюють |

Тому посилання-кнопці (`<a class="button">`) з вертикальними відступами потрібне `display: inline-block` (або `block`).

## Зображення в блоках

```css
.photo-card img {
  display: block;   /* прибирає «щілину» під картинкою — місце під літери з хвостиками */
  max-width: 100%;  /* не ширше за батька */
  height: auto;     /* пропорції зберігаються */
}
```

## overflow

Коли вміст більший за блок фіксованої висоти, він «вилазить». `overflow: hidden` обрізає його, `overflow: auto` додає прокрутку лише за потреби. Обрізати текст — небезпечно: при збільшенні шрифту частина просто зникне.

## Блокова модель у DevTools

DevTools → Elements → **Computed**: угорі схема з чотирма шарами й точними числами. При наведенні на елемент сторінка підсвічує вміст (блакитним), padding (зеленим) і margin (помаранчевим).

## Підсумок

- Вміст → padding → border → margin.
- `box-sizing: border-box` для всіх: тоді `width` — це ширина від рамки до рамки.
- `max-width` + `margin: 0 auto` — центрований блок, що не вилазить за екран.
- Вертикальні margin сусідніх блоків схлопуються до більшого.
- Inline-елементи ігнорують `width`, `height` і вертикальні відступи — потрібен `inline-block` чи `block`.
