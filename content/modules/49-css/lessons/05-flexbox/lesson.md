# Flexbox

**Flexbox** — розкладка в **один вимір**: у рядок або в стовпчик. Шапка з логотипом і меню, рядок кнопок, теги, картка з кнопкою внизу — усе це Flexbox. Він сам ділить вільне місце, вирівнює елементи й переносить їх на новий рядок.

## Контейнер і елементи

Панель інструментів фотогалереї:

```html
<div class="toolbar">
  <button type="button">Завантажити</button>
  <button type="button">Новий альбом</button>
  <input type="search" aria-label="Пошук фото">
</div>
```

```css
.toolbar {
  display: flex;        /* .toolbar — flex-контейнер, його діти — flex-елементи */
  gap: 12px;            /* відстань між елементами */
  align-items: center;  /* по центру по вертикалі */
}
```

`display: flex` діє лише на **прямих дітей**. Онуки розкладаються як звичайно.

## Дві осі

- **Головна вісь** — напрям, у якому стоять елементи: `flex-direction: row` (за замовчуванням, зліва направо) або `column` (згори вниз).
- **Поперечна вісь** — перпендикулярна до неї.

| Властивість | Вісь | Значення |
|---|---|---|
| `justify-content` | головна | `flex-start`, `center`, `flex-end`, `space-between`, `space-around`, `space-evenly` |
| `align-items` | поперечна | `stretch` (за замовчуванням — однакова висота), `center`, `flex-start`, `flex-end`, `baseline` |
| `gap` | обидві | відстань між елементами (і між рядками при перенесенні) |

У `column` осі міняються місцями: `justify-content` вирівнює **по вертикалі**, `align-items` — **по горизонталі**. Це найчастіша плутанина.

## Перенесення й гнучкі розміри

```css
.albums {
  display: flex;
  flex-wrap: wrap;   /* не влізли — переносяться на новий рядок */
  gap: 16px;
}
.album {
  flex: 1 1 200px;   /* grow shrink basis */
}
```

`flex` — скорочення трьох властивостей:

| Частина | Значення |
|---|---|
| `flex-grow: 1` | забирати частку вільного місця |
| `flex-shrink: 1` | стискатися, якщо місця бракує |
| `flex-basis: 200px` | початкова ширина, від якої все рахується |

Тут кожен альбом хоче 200 px; у рядок влазить скільки влізе, а залишок місця ділиться між ними порівну. `flex: 1` — те саме, що `1 1 0%`: усі елементи рівної ширини.

> [!NOTE]
> Flex-елемент за замовчуванням не стискається вужче за свій вміст (`min-width: auto`). Довга назва файлу чи URL розпирає картку й ламає рядок. Ліки: `min-width: 0` на елементі (і `overflow-wrap: anywhere` для тексту).

## Корисні прийоми

```css
.header { display: flex; align-items: center; gap: 24px; }
.header .account { margin-left: auto; }   /* відштовхнути вправо: auto забирає все вільне місце */

.card { display: flex; flex-direction: column; }
.card .button { margin-top: auto; }       /* кнопка — притиснута донизу картки */

.center { display: flex; justify-content: center; align-items: center; }  /* будь-що по центру */
```

`align-self` перевизначає `align-items` для одного елемента.

## order і доступність

`order: -1` ставить елемент **візуально** першим, але в HTML він лишається на своєму місці. Клавіша Tab і екранний читач ідуть за HTML — людина бачить один порядок, а фокус стрибає в іншому. Те саме з `flex-direction: row-reverse`. Якщо порядок важливий — міняй його в HTML.

## Flexbox у DevTools

У DevTools біля flex-контейнера є мітка **flex**: клік показує осі, gap і розміри елементів прямо на сторінці, а у вкладці Styles є редактор вирівнювання з іконками.

## Підсумок

- `display: flex` на батьку → діти стають у рядок; `flex-direction: column` — у стовпчик.
- `justify-content` — уздовж головної осі, `align-items` — поперек; `gap` — відстань.
- `flex-wrap: wrap` + `flex: 1 1 <basis>` — гнучкий рядок карток.
- `margin-left: auto` відштовхує елемент, `margin-top: auto` у стовпчику притискає донизу.
- Порядок для очей і для клавіатури має збігатися — не міняй його через `order`.
