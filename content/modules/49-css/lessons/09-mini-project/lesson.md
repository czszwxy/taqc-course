# Міні-проєкт: стилі сторінки товару

У модулі HTML ти розмітив(ла) сторінку годинника Gadgetly Watch 3. Тепер зробимо її гарною — так, щоб нею було зручно користуватися з мишкою, клавіатурою, на великому екрані й при збільшенні. HTML той самий (лише з класами для стилів), увесь CSS — твій.

## Порядок роботи

Великий файл стилів легко перетворити на хаос. Порядок, який тримає його в руках:

1. **Скидання**: `box-sizing: border-box` для всіх, `margin: 0` для `body`.
2. **Токени**: кольори, відступи, радіуси — змінні на `:root`.
3. **Основа**: шрифт, розмір у `rem`, інтерліньяж, колір тексту й посилань.
4. **Розкладка**: Grid для областей сторінки, Flexbox для шапки й меню.
5. **Компоненти**: кнопка, ціна, таблиця, картки відгуків.
6. **Стани**: `:hover`, `:focus-visible`, skip link при фокусі.
7. **Перевірка**: контраст, Tab по всій сторінці, збільшення 200 %, DevTools.

## Каркас файлу

```css
/* 1. Скидання */
*, *::before, *::after { box-sizing: border-box; }
body { margin: 0; }

/* 2. Токени */
:root {
  --color-brand: #1d4ed8;
  --color-text: #1f2937;
  --color-muted: #4b5563;
  --color-line: #e5e7eb;
  --space: 16px;
  --radius: 8px;
}

/* 3. Основа */
body { font-family: system-ui, sans-serif; font-size: 1rem; line-height: 1.6; color: var(--color-text); }

/* 4. Розкладка */
.layout { display: grid; grid-template-columns: 1fr 280px; gap: calc(var(--space) * 2); }

/* 5. Компоненти … 6. Стани … */
```

Коментарі-розділи допомагають і тобі, і рев'юеру: одразу видно, де шукати.

## Типові пастки цього проєкту

- **Фото ширше за колонку.** Атрибут `width="600"` у `<img>` — це пропорції, а не заборона стискатися: допоможе `max-width: 100%; height: auto`.
- **Бічна колонка «падає» вниз.** Без Grid `<aside>` іде після статті. `grid-template-columns: 1fr 280px` ставить їх поруч, а хлібні крихти над обома — `grid-column: 1 / -1`.
- **Стара ціна «зникає».** Сірий `<del>` легко зробити заблідим — тримай контраст 4,5 : 1 і для нього.
- **Таблиця з подвійними лініями.** `border-collapse: collapse` зливає рамки сусідніх клітинок в одну.
- **Кнопка без фокусу.** Скидання стилів кнопки (`border: 0`) не має прибирати `outline` — додай `:focus-visible`.

## Як перевірити сторінку

- **Контраст**: DevTools → вибери текст → піпетка кольору показує співвідношення.
- **Клавіатура**: Tab від початку — skip link з'являється, фокус видно на кожному елементі.
- **Збільшення**: Ctrl + «+» до 200 % — нічого не обрізається і не накладається.
- **Lighthouse** → Accessibility: швидка автоматична перевірка контрасту й назв.

> [!TIP]
> Збережи `index.html` і `styles.css` у репозиторій портфоліо разом зі сторінкою з модуля HTML: «до» і «після» CSS добре показують, що ти вмієш.

## Підсумок

- Порядок: скидання → токени → основа → розкладка → компоненти → стани → перевірка.
- Grid для областей, Flexbox для рядків усередині.
- Контраст, фокус і збільшення — частина «готово», а не «колись потім».
