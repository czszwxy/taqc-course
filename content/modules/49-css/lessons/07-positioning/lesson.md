# Позиціонування та накладання

Flexbox і Grid розставляють блоки **в потоці**: один за одним, не перекриваючи. Але інколи елемент має стояти поверх інших: значок «−20%» у кутку картки, липка шапка, кнопка чату в кутку вікна, підказка над кнопкою. Для цього — `position`.

## Значення position

| Значення | Де стоїть | Від чого рахуються `top` / `left`… | Займає місце в потоці? |
|---|---|---|---|
| `static` (за замовчуванням) | у потоці | не працюють | так |
| `relative` | у потоці, але може зсунутися | від свого звичайного місця | так (місце лишається) |
| `absolute` | поверх інших | від найближчого **позиціонованого** предка | **ні** |
| `fixed` | поверх інших | від **вікна** — не прокручується | ні |
| `sticky` | у потоці, доки не дійде до межі | «прилипає», коли прокрутка доходить до `top` | так |

## Значок у кутку: relative + absolute

Фото в галереї з позначкою «Нове»:

```css
.photo-card {
  position: relative;      /* тепер він — точка відліку для absolute-нащадків */
}
.photo-card .label {
  position: absolute;
  top: 8px;
  right: 8px;
}
```

Без `position: relative` на картці значок шукав би позиціонованого предка далі вгору — і опинився б у кутку сторінки. Це найчастіша помилка з `absolute`.

`inset: 0` — скорочення `top: 0; right: 0; bottom: 0; left: 0` (розтягнути на весь батьківський блок, наприклад, для напівпрозорого шару поверх фото).

## Липка шапка: sticky

```css
.site-header {
  position: sticky;
  top: 0;                    /* до якої межі прокручується, перш ніж прилипнути */
  z-index: 10;               /* поверх вмісту, що пропливає під нею */
  background-color: #fff;    /* інакше текст просвічуватиме крізь прозору шапку */
}
```

Чому sticky «не липне»:

- немає `top` (чи `bottom`);
- у предка `overflow: hidden` / `auto` — шапка липне всередині нього, а не вікна;
- батько закінчився: sticky-елемент не виходить за межі свого батька.

## Накладання: z-index

Позиціоновані елементи, що перекриваються, малюються в порядку HTML: пізніший — зверху. `z-index` змінює це: більше число — ближче до користувача. Він працює для позиціонованих елементів (і для flex / grid-елементів).

Підступ — **контекст накладання**: елемент з `z-index` (а також з `opacity` менше 1 чи `transform`) створює «шар», і всі його нащадки змагаються лише всередині нього. Модальне вікно з `z-index: 9999` усередині шапки з `z-index: 1` не перекриє вміст з `z-index: 2`. Ліки — тримати шари простими: 1 для шапки, 100 для модалок, а не 9999 всюди.

## Зсунути, не чіпаючи сусідів: transform

`transform: translateY(-2px)` зсуває елемент візуально, а місце в потоці лишається. Анімувати `transform` і `opacity` — найдешевше для браузера (наступний урок).

## Сховати лише візуально

Іноді текст потрібен екранному читачу, але не на екрані: назва кнопки-іконки, підпис поля пошуку, якщо поруч і так видно лупу. `display: none` і `visibility: hidden` прибирають текст **і** з дерева доступності — тому використовують спеціальний клас:

```css
.visually-hidden {
  position: absolute;
  width: 1px;
  height: 1px;
  padding: 0;
  margin: -1px;
  overflow: hidden;
  clip-path: inset(50%);
  white-space: nowrap;
  border: 0;
}
```

```html
<button type="button" class="icon-button">
  <svg aria-hidden="true" …>…</svg>
  <span class="visually-hidden">Додати фото в альбом</span>
</button>
```

## Посилання «Перейти до вмісту» з'являється при фокусі

```css
.skip-link {
  position: absolute;
  left: 8px;
  top: 8px;
  transform: translateY(-200%);   /* за верхнім краєм екрана */
}
.skip-link:focus {
  transform: none;                /* Tab — і воно видно */
}
```

Не ховай його через `display: none`: тоді на нього не можна перейти клавішею Tab — і воно втрачає сенс.

## Підсумок

- `relative` — точка відліку; `absolute` — поверх, від позиціонованого предка; `fixed` — від вікна; `sticky` — липне при прокрутці.
- Значок у кутку = `relative` на картці + `absolute` на значку.
- Sticky потребує `top`, фону і часто `z-index`; `overflow` предка може його зламати.
- `z-index` діє всередині контексту накладання — тримай шари простими.
- Приховати лише візуально — `.visually-hidden`; skip link — за екраном, доки не отримає фокус.
