# CSS Grid

Flexbox розкладає в **один** вимір. **Grid** — у два: рядки й колонки одночасно. Сітка фотографій, каталог товарів, розкладка сторінки з шапкою, бічною колонкою і футером — це Grid.

## Колонки, рядки, gap

Фотогалерея з трьома рівними колонками:

```css
.gallery {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;   /* три колонки, вільне місце порівну */
  gap: 16px;                            /* між колонками і рядками */
}
```

- `fr` — частка **вільного** місця. `2fr 1fr` — перша колонка вдвічі ширша.
- Можна змішувати: `240px 1fr` — фіксована бічна колонка і гнучкий вміст.
- `repeat(3, 1fr)` — те саме, що `1fr 1fr 1fr`.
- Рядки створюються самі, коли елементів більше, ніж колонок. Елементи в одному рядку однакової висоти.

## Сітка без медіазапитів: auto-fill і minmax

```css
.gallery {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
  gap: 16px;
}
```

Читається так: «стільки колонок, скільки влізе, кожна не вужча за 200 px, а залишок місця — порівну». На комп'ютері вийде 4–5 колонок, на планшеті — 3, на телефоні — 1–2, і жодного рядка про ширину екрана.

- `minmax(200px, 1fr)` — колонка від 200 px до однієї частки.
- `auto-fill` залишає порожні колонки, якщо елементів мало; `auto-fit` стискає їх, і наявні елементи розтягуються на всю ширину.

## Елемент на кілька колонок і рядків

```css
.photo--wide { grid-column: span 2; }   /* займає дві колонки */
.photo--tall { grid-row: span 2; }      /* два рядки */
.photo--first { grid-column: 1 / 3; }   /* від лінії 1 до лінії 3 */
```

Лінії сітки нумеруються з 1, від лівого краю; `-1` — остання лінія: `grid-column: 1 / -1` — на всю ширину.

## Розкладка сторінки: grid-template-areas

```css
.page {
  display: grid;
  grid-template-columns: 240px 1fr;
  grid-template-areas:
    "header  header"
    "sidebar main"
    "footer  footer";
  gap: 16px;
}
.page > header { grid-area: header; }
.page > nav    { grid-area: sidebar; }
.page > main   { grid-area: main; }
.page > footer { grid-area: footer; }
```

Області малюються «картинкою» з назв: кожен рядок у лапках — рядок сітки, однакові назви поруч — одна область на кілька клітинок. Змінити розкладку (наприклад, для телефона) — переписати лише ці рядки.

> [!IMPORTANT]
> Grid дозволяє поставити блок будь-куди незалежно від HTML. Але Tab і екранний читач ідуть за **HTML**. Пиши HTML у логічному порядку (вміст `main` — раніше за бічну навігацію, якщо він головний), а розміщуй CSS-ом. Візуальний порядок не має суперечити порядку читання.

## Grid чи Flexbox?

| Flexbox | Grid |
|---|---|
| один вимір: рядок або стовпчик | два виміри: рядки й колонки разом |
| розміри від вмісту: «скільки влізе» | розміри від сітки: «колонки рівні» |
| шапка, рядок кнопок, теги, вміст картки | каталог, галерея, розкладка сторінки, форма з вирівняними підписами |

Їх часто поєднують: сторінка — Grid, шапка всередині — Flexbox, картки каталогу — Grid, вміст картки — Flexbox у стовпчик.

## Grid у DevTools

Мітка **grid** біля контейнера в Elements вмикає накладку: номери ліній, назви областей і розміри колонок прямо на сторінці.

## Підсумок

- `display: grid` + `grid-template-columns` + `gap`; `fr` — частка вільного місця.
- `repeat(auto-fill, minmax(200px, 1fr))` — сітка, що сама вирішує кількість колонок.
- `grid-column: span 2`, `1 / -1` — на кілька колонок чи на всю ширину.
- `grid-template-areas` — розкладка сторінки «картинкою»; HTML лишається в логічному порядку.
- Один вимір — Flexbox, два — Grid; їх поєднують.
