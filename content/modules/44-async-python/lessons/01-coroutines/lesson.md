# Корутини і цикл подій

Бекенд більшість часу **чекає**: на відповідь бази, на зовнішній API, на файл. Звичайна програма в цей час просто стоїть. Якщо сторінці погоди треба дані з трьох сервісів по секунді кожен — це три секунди, хоча процесор нічого не робив.

```text
послідовно:  [сервіс A ███]·[сервіс B ███]·[сервіс C ███]      ≈ 3 с
asyncio:     [сервіс A ███]
             [сервіс B ███]                                     ≈ 1 с
             [сервіс C ███]
```

**asyncio** дозволяє одному потоку не стояти: поки один запит чекає на мережу, Python виконує інший. Це **конкурентність** (багато справ «одночасно в процесі»), а не паралельність (кілька ядер рахують одночасно) — потік один.

## Корутина

```python
import asyncio

async def fetch_forecast(city: str) -> str:
    print(f"asking about {city}")
    await asyncio.sleep(1)                 # «чекаємо на мережу»
    return f"{city}: +12°C"

async def main():
    report = await fetch_forecast("Lviv")
    print(report)

asyncio.run(main())
```

| Що | Значення |
|---|---|
| `async def` | оголошує **корутинну функцію**; її виклик нічого не виконує, а повертає об'єкт-корутину |
| `await вираз` | «виконай це і, поки воно чекає, віддай керування іншим»; можна лише всередині `async def` |
| `asyncio.run(main())` | створює **цикл подій**, виконує корутину до кінця і закриває цикл — один раз, на вході програми |

Цикл подій схожий на кухаря з кількома каструлями: поставив воду (`await`), поки вона закипає — нарізає овочі. Він не готує дві страви однією рукою одночасно, але й не стоїть біля каструлі.

## Найчастіша помилка: забутий await

```python
async def main():
    report = fetch_forecast("Lviv")        # ❌ без await
    print(report)                          # <coroutine object fetch_forecast at 0x...>
```

Без `await` функція навіть не почала виконуватися: ти отримуєш об'єкт-корутину, а Python пізніше попередить `RuntimeWarning: coroutine 'fetch_forecast' was never awaited`. Якщо далі цей «результат» додати до числа — буде `TypeError`.

## Блокувальний код зупиняє всіх

```python
async def bad():
    time.sleep(1)               # ❌ зупиняє ВЕСЬ цикл: жодна інша корутина не виконується
    requests.get(url)           # ❌ теж блокує — бібліотека requests не асинхронна

async def good():
    await asyncio.sleep(1)      # ✅ віддає керування на час очікування
    await client.get(url)       # ✅ асинхронний клієнт (httpx.AsyncClient, урок 5)
```

Цикл подій **кооперативний**: корутина віддає керування лише на `await`. Будь-який довгий виклик без `await` — `time.sleep`, синхронна база, важкі обчислення — зупиняє всі інші задачі. Як жити з такими бібліотеками, розберемо в уроці 8 (`asyncio.to_thread`).

## Синхронне й асинхронне разом

- З асинхронного коду викликати звичайну **швидку** функцію можна як завжди: `round(price * 1.2)`.
- Зі звичайного коду корутину запускають через `asyncio.run(...)` — зазвичай одним викликом на вході скрипта.
- `asyncio.run` не можна викликати всередині вже запущеного циклу (наприклад, з іншої корутини) — там пишуть `await`.

> [!TIP]
> Кнопка **Run** у задачах модуля виконує твій файл. Щоб побачити результат, додай унизу `if __name__ == "__main__": print(asyncio.run(...))`.

## Типові помилки

| Помилка | Наслідок |
|---|---|
| Виклик корутини без `await` | об'єкт-корутина замість результату, попередження «never awaited» |
| `await` у звичайній `def` | `SyntaxError` |
| `time.sleep` / `requests` в `async def` | увесь застосунок «замерзає» на цей час |
| `asyncio.run` усередині корутини | `RuntimeError: asyncio.run() cannot be called from a running event loop` |
| Чекати, що async пришвидшить обчислення | не пришвидшить: виграш лише там, де є очікування |

> [!QA]
> Асинхронний код ламається не лише логікою, а й **порядком**: дві корутини можуть завершитися в несподіваній послідовності. Тести таких функцій перевіряють результат, винятки й те, що код справді виконується конкурентно (а не по черзі) — у наступних уроках ми рахуватимемо одночасні виклики у фейкових сервісах.

## Підсумок

- asyncio — конкурентність в одному потоці: поки одне чекає, виконується інше.
- `async def` повертає корутину; `await` виконує її і віддає керування на час очікування.
- `asyncio.run(main())` — вхід у асинхронний світ, один раз.
- Без `await` корутина не виконується; блокувальні виклики в `async def` зупиняють усіх.
