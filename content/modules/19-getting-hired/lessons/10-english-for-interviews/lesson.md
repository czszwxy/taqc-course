# Англійська на співбесіді QA

Більшість українських IT-компаній працюють із закордонними клієнтами, тож англійська — частина роботи: баг-репорти, коментарі в Jira, дзвінки з клієнтом. Кандидати-джуни розповідають, що **саме англійська** нерідко зупиняла їх навіть після успішної технічної співбесіди. Добра новина: для співбесіди потрібна не «ідеальна» англійська, а **підготовлені відповіді** на передбачувані питання і кілька фраз-рятівників.

## Як перевіряють англійську

- **HR-дзвінок частково англійською**: 5–15 хвилин «розкажи про себе», «чому QA», «твій проєкт».
- **Частина технічної співбесіди англійською**: 2–3 теоретичні питання або «опиши баг, який ти знайшов».
- **Окремий English check** з викладачем компанії або **запис** короткого відео / читання тексту.
- **Тестове завдання англійською**: README і баг-репорти — теж перевірка мови.

Орієнтир: для багатьох аутсорс-компаній мінімум — **B1** (впевнено розповідаєш про себе і роботу), для продуктових і міжнародних — **B2**.

## Що підготувати англійською заздалегідь

1. **Tell me about yourself** (1–2 хв): present → past → future.
2. **Describe your project**: що тестує, стек, твоя роль, результат.
3. **Describe a bug you found**: де, як знайшов, кроки, наслідок, що далі.
4. **Explain a concept**: regression testing, severity vs priority, test pyramid.
5. **Why QA? Why our company?**
6. **Your questions to the interviewer**.

> [!TIP]
> Запиши ці відповіді, вивчи **ключові фрази**, а не текст дослівно. Дослівно завчене звучить неприродно і «ламається», коли питання трохи інше.

## Фрази-рятівники

| Ситуація | Фраза |
|---|---|
| Не почув / не зрозумів | *Sorry, could you repeat the question, please?* · *Could you rephrase that?* |
| Уточнити | *Do you mean …?* · *Just to make sure I understand: …?* |
| Виграти час | *That's a good question, let me think for a second.* |
| Структурувати | *First, … Then, … Finally, …* · *There are two main reasons.* |
| Не знаєш | *I'm not sure, but I think …* · *I haven't worked with it yet, but I know that …* |
| Приклад | *For example, in my project I …* |
| Завершити відповідь | *So, in short, …* · *Does that answer your question?* |

## Словник QA

| English | Значення |
|---|---|
| to reproduce a bug, steps to reproduce | відтворити баг, кроки відтворення |
| expected / actual result | очікуваний / фактичний результат |
| to report / file a bug | завести баг |
| edge case, corner case | крайній випадок |
| flaky test | нестабільний тест |
| regression, to retest | регресія, перевірити фікс |
| blocker, workaround | блокуюча проблема, обхідний шлях |
| root cause | першопричина |
| test coverage | покриття тестами |
| environment (staging, production) | середовище |
| to deploy, release, build | розгорнути, реліз, збірка |
| stand-up, sprint, backlog, estimate | щоденна зустріч, спринт, беклог, оцінка |
| requirement, acceptance criteria | вимога, критерії приймання |
| to investigate, to figure out | дослідити, розібратися |

## Типові помилки

| Так кажуть | Правильно |
|---|---|
| I *have* 2 years experience in sales | I *have two years of* experience in sales · I *worked* in sales for two years |
| I *am working* here since 2023 | I *have been working* here since 2023 |
| *Explain me*, please | *Explain to me*, please · *Could you explain …?* |
| It *depends of* the project | It *depends on* the project |
| We *discussed about* the bug | We *discussed* the bug |
| *How it works?* | *How does it work?* |
| I *did* a bug report | I *reported a bug* · I *wrote* a bug report |
| I *made* tests | I *wrote / ran* tests |
| *On* the screenshot | *In* the screenshot |
| I *passed* courses | I *completed / took* a course |

> [!QA]
> Найкраща практика — **говорити**. Розкажи свій «Tell me about yourself» уголос 5 разів, запиши на диктофон, попроси Claude провести співбесіду англійською і виправити помилки (кнопка **Copy for review** у письмових завданнях).

## Підсумок

- Англійську перевіряють на HR-дзвінку, частиною технічної співбесіди або окремим тестом; орієнтир — B1+.
- Підготуй 6 відповідей англійською: about yourself, project, bug, concept, why QA, твої питання.
- Тримай під рукою фрази для уточнення, «виграти час» і чесного «не знаю».
- Вивчи словник QA і виправ типові помилки (*experience*, *depends on*, *explain to me*).
