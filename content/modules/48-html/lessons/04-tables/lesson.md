# Таблиці

Таблиця — для **даних**, у яких рядки й стовпці мають значення: розклад, історія замовлень, порівняння характеристик. Людина очима бачить, що «10:00–18:00» стоїть у рядку «Центральна» і стовпці «Сб». Екранний читач цього не бачить — йому це треба **сказати розміткою**.

> [!WARNING]
> Колись таблицями верстали цілі сторінки: меню в одній клітинці, вміст в іншій. Так робити не можна: читач оголошує «таблиця, 3 стовпці» там, де даних немає. Розкладку сторінки будує CSS (Grid і Flexbox — у наступному модулі).

## Будова таблиці

Розклад роботи філій міської бібліотеки:

```html
<table>
  <caption>Розклад роботи філій бібліотеки</caption>
  <thead>
    <tr>
      <th scope="col">Філія</th>
      <th scope="col">Пн–Пт</th>
      <th scope="col">Сб</th>
      <th scope="col">Нд</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">Центральна</th>
      <td>9:00–20:00</td>
      <td>10:00–18:00</td>
      <td>вихідний</td>
    </tr>
    <tr>
      <th scope="row">Дитяча</th>
      <td>10:00–18:00</td>
      <td colspan="2">вихідні</td>
    </tr>
  </tbody>
</table>
```

| Елемент | Що це |
|---|---|
| `<table>` | уся таблиця |
| `<caption>` | назва таблиці — **перший** елемент усередині `<table>`; її оголошує читач і бачать усі |
| `<thead>` / `<tbody>` / `<tfoot>` | групи рядків: заголовки стовпців / дані / підсумки |
| `<tr>` | рядок (table row) |
| `<th>` | клітинка-заголовок (table header) |
| `<td>` | клітинка з даними (table data) |

## Навіщо th і scope

Коли користувач читача переходить клітинками, він чує не лише значення, а й заголовки: «Центральна, Сб, 10:00–18:00». Для цього:

- заголовки — у `<th>`, а не в `<td><b>…</b></td>` (жирний шрифт читач не «бачить»);
- `scope="col"` — заголовок для всього **стовпця**, `scope="row"` — для всього **рядка**.

Перший стовпець часто теж заголовок: назва філії, товару, характеристики. Тому в рядках `<tbody>` перша клітинка — `<th scope="row">`.

## Об'єднання клітинок

- `colspan="2"` — клітинка займає два **стовпці** («вихідні» на суботу й неділю).
- `rowspan="2"` — два **рядки**.

Рахуй клітинки: у кожному рядку їхня сума (з урахуванням `colspan`) має дорівнювати кількості стовпців, інакше таблиця «з'їде».

## Підсумки: tfoot

```html
<tfoot>
  <tr>
    <th scope="row" colspan="3">Видано книжок за тиждень</th>
    <td>1 284</td>
  </tr>
</tfoot>
```

`<tfoot>` — рядки з підсумками. Його кладуть після `<tbody>`, і він залишається в кінці таблиці.

## Складні таблиці

Якщо заголовків кілька рівнів (наприклад, «Сб» розбито на «ранок» і «вечір»), `scope` уже не вистачає. Тоді кожен `<th>` отримує `id`, а `<td>` перелічує свої заголовки: `headers="sat morning"`. Але спершу подумай, чи не простіше розбити таблицю на дві.

## Таблиця на телефоні

Широка таблиця не влазить у 375 px. Не перетворюй її на `<div>`-и — загорни в контейнер з горизонтальною прокруткою (`overflow-x: auto` у CSS, модуль про адаптивний дизайн). Структура таблиці залишиться, а прокручуватиметься лише вона, не вся сторінка.

## Типові помилки

- Заголовки в `<td><b>` замість `<th>` — читач не зв'яже значення з назвою стовпця.
- Назва таблиці абзацом над нею замість `<caption>`.
- Порожні клітинки замість даних «немає» — краще написати «—» чи «немає».
- Таблиця для розкладки: дві колонки сторінки, сітка карток товарів.

## Підсумок

- Таблиця — лише для даних з рядками й стовпцями.
- `<caption>` — назва; `<thead>`, `<tbody>`, `<tfoot>` — групи рядків.
- Заголовки — `<th>` з `scope="col"` / `scope="row"`; дані — `<td>`.
- `colspan` / `rowspan` об'єднують клітинки — рахуй, щоб рядки сходилися.
- На телефоні — прокрутка таблиці, а не її знищення.
