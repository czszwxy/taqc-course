# Текст: заголовки, абзаци, списки

Більшість сторінок — це текст. Від того, як він розмічений, залежить, чи зможе людина **швидко знайти** потрібне: очима — за заголовками й списками, а з екранним читачем — перестрибуючи від заголовка до заголовка (у NVDA це клавіша **H**). Розмітка тексту — це зміст сторінки, а не його оформлення.

## Заголовки — це зміст сторінки

`<h1>`…`<h6>` — шість рівнів заголовків. Разом вони утворюють «зміст» сторінки, як у книжці. Сторінка рецепта на кулінарному сайті:

```html
<h1>Сирники зі сметаною</h1>
  <h2>Інгредієнти</h2>
  <h2>Приготування</h2>
    <h3>Тісто</h3>
    <h3>Смаження</h3>
  <h2>Відгуки</h2>
```

Екранний читач покаже користувачу список: «заголовок 1 Сирники зі сметаною, заголовок 2 Інгредієнти…» — і людина одразу перейде до «Приготування».

Правила:

1. **Один `<h1>`** — головна тема сторінки (назва товару, статті, розділу). Стандарт технічно дозволяє кілька, але один `<h1>` — найзрозуміліший варіант для людей і пошуковиків.
2. **Не пропускай рівні вниз**: після `<h2>` іде `<h3>`, а не `<h5>`. Повертатися вгору можна на будь-який рівень: після `<h3>` — знову `<h2>`.
3. **Рівень — це не розмір шрифту.** Розмір задає CSS. Не бери `<h4>` лише тому, що він «гарно дрібний».
4. **Не підробляй заголовки**: `<p><b>Інгредієнти</b></p>` виглядає як заголовок, але для екранного читача це звичайний абзац — у змісті його немає.
5. І навпаки: не роби заголовком текст, який лише має бути великим («Знижка 20%!» у банері — це абзац з `<strong>`, а не розділ).

> [!NOTE]
> Колись планували, що `<h1>` всередині `<section>` автоматично стане «нижчим» рівнем (document outline algorithm). Браузери цього так і не зробили, а у 2022 році алгоритм прибрали зі стандарту. Рівень заголовка — це завжди його цифра.

## Абзаци та розриви

- `<p>` — абзац. Новий абзац — новий `<p>`, а не `<br><br>`.
- `<br>` — розрив рядка **всередині** тексту, де він є частиною змісту: адреса, вірш.
- `<hr>` — тематична зміна (наприклад, між двома частинами оповідання), а не «лінія для краси» — лінію малює CSS.

## Слова з особливим значенням

| Елемент | Значення | Приклад |
|---|---|---|
| `<strong>` | важливе, серйозне | `<strong>Не виймай флешку під час запису.</strong>` |
| `<em>` | смисловий наголос, що змінює зміст | «Книжку треба повернути `<em>завтра</em>`» (а не сьогодні) |
| `<mark>` | підсвічено для поточного контексту | знайдене слово в результатах пошуку |
| `<small>` | примітка, дрібний шрифт за змістом | «Ціни вказано з ПДВ» |
| `<b>` / `<i>` | виділити без «важливості» / інший голос | ключові слова в анотації / назва терміна, іншомовне слово |
| `<code>`, `<kbd>` | код / клавіші, які натискають | `<kbd>Ctrl</kbd> + <kbd>F</kbd>` |
| `<abbr title="…">` | абревіатура з розшифровкою | `<abbr title="Міжнародний стандартний книжковий номер">ISBN</abbr>` |
| `<time datetime="…">` | дата чи час, зрозумілі програмам | `<time datetime="2026-12-01">1 грудня</time>` |
| `<del>` / `<ins>` | видалено / додано | стара ціна, виправлення в тексті |

`<b>` та `<i>` не застарілі — просто вони не означають «важливо». Якщо сумніваєшся — питай себе «що це означає?», а не «як це має виглядати?».

## Списки

```html
<ul>                       <!-- порядок не важливий -->
  <li>Борошно — 3 ст. л.</li>
  <li>Яйце — 1 шт.</li>
</ul>

<ol>                       <!-- порядок важливий: кроки, рейтинги -->
  <li>Змішай сир з яйцем.</li>
  <li>Додай борошно.</li>
</ol>

<dl>                       <!-- пари «термін — опис» -->
  <dt>Час приготування</dt>
  <dd>25 хвилин</dd>
  <dt>Порцій</dt>
  <dd>4</dd>
</dl>
```

Екранний читач оголошує «список, 2 пункти» — людина одразу знає обсяг. Список з дефісів чи `<br>` такої інформації не дає.

**Вкладений список** кладуть **всередину** `<li>`:

```html
<ul>
  <li>Молочні продукти
    <ul>
      <li>Сир кисломолочний</li>
      <li>Сметана</li>
    </ul>
  </li>
</ul>
```

У `<ol>` є атрибути `start="5"` (почати з 5) і `reversed` (рахувати назад — для «топ-10»).

## Цитати й код

- `<blockquote>` — довга цитата окремим блоком, `<q>` — коротка в рядку (лапки браузер додасть сам).
- `<pre>` зберігає пробіли й переноси як є; для фрагментів коду — `<pre><code>…</code></pre>`.

## Спецсимволи

Символи `<` і `&` браузер сприймає як початок тегу й спецсимволу, тому в тексті їх записують так:

| Пишеш | Бачиш | Навіщо |
|---|---|---|
| `&lt;` / `&gt;` | `<` / `>` | показати тег як текст: «тег `&lt;p&gt;`» |
| `&amp;` | `&` | «Barnes `&amp;` Noble» |
| `&nbsp;` | нерозривний пробіл | «10&nbsp;грн», «м.&nbsp;Київ» — щоб число не відірвалося від одиниці при переносі |
| `&copy;` | © | «© 2026» |

З `utf-8` більшість символів (—, «», ©, ₴) можна просто набирати як є.

## Типові помилки

- Заголовок вибрано за розміром: `<h4>` одразу після `<h1>`.
- «Заголовок» з `<p><b>` або `<div class="title">` — у змісті сторінки його немає.
- Список з дефісів і `<br>` замість `<ul>`.
- Кроки інструкції в `<ul>`: для послідовності, де порядок важливий, потрібен `<ol>`.
- `<strong>` на пів сторінки: коли важливе все — не важливе нічого.

## Підсумок

- Заголовки утворюють зміст: один `<h1>`, рівні вниз без пропусків, рівень ≠ розмір.
- Абзац — `<p>`; `<br>` — лише для рядків адреси чи вірша.
- Обирай елемент за значенням: `<strong>` — важливо, `<em>` — наголос, `<mark>` — знайдено, `<time>` — дата.
- `<ul>` — без порядку, `<ol>` — з порядком, `<dl>` — пари «назва — значення»; вкладений список — усередині `<li>`.
- `<` і `&` у тексті — `&lt;` і `&amp;`, нерозривний пробіл — `&nbsp;`.
